主要功能

任务与日历

在四态看板推进任务，设置排期和到期提醒。支持只读接入钉钉日历与待办。

禅道项目与 BUG

同步参与的项目、负责的执行和指派给自己的 BUG。支持提交 BUG 和回写执行进度。

AI 和知识库

配置模型和 Agent，使用文字、图片和文档发起对话，查看回答引用。

应用与邮件

集中打开常用应用，从一个界面收发多个邮箱的邮件。

日常工具

查询汇率、换算多种货币、生成 2FA 验证码，也可以管理 NATAPP 隧道。

备份和恢复

工作数据默认保存在本机，支持本地 ZIP 备份与 S3 定时备份。

0.2.0 新功能

以下功能自 0.2.0 起可用。

查看 README ↗

会议助手

录音时用本机 X-ASR 实时转写中文和英文，停止录音后可区分说话人。支持选择和检测麦克风，也可配置转录 API。

配置文本模型后，可生成会议纪要、脑图和行动项，并将行动项转为任务。

应用中心与共享链接

从浏览器书签或 Excel 批量导入应用，按分类管理和收藏。共享链接可分组，并按创建人和日期筛选。

密码库

应用和服务器凭据分开管理，支持 Excel 导入、按需查看和复制。凭据加密保存在本机。

我的任务与邮件

在「我的任务」切换看板、日历、列表和完成回顾。写邮件支持富文本正文。

工具箱与备份

NATAPP 可同步、配置和启动隧道。S3 滚动保留最近 10 份成功备份，语音模型文件独立保存。
