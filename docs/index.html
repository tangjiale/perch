CAPABILITIES

为真实工作设计的每一处细节

01

任务与看板

待做、进行中、已挂起、已完成，四态看板随手推进。管理开始与结束排期，为重要任务设置到期或提前提醒。

02

项目与禅道

同步本人参与的项目、负责的执行和指派给自己的 BUG。核实指派人与时间、查看操作历史，编辑执行后回写禅道。

03

日历与节奏

月、周、日和列表视图串起任务排期。只读接入钉钉 CalDAV 日历与待办，农历、节气和调休同屏可见。

04

AI 工作伙伴

选择 Agent、模型与知识库，发送文字和图片，边聊边切换模型。流式回复保留知识引用、实际用量与响应耗时。

05

随手可用的工具

汇率查询与多币种换算、2FA 动态验证码、NATAPP 隧道管理。常用应用和多个邮箱，也有各自的位置。

06

数据有自己的归处

本地保存工作数据与加密凭据。用本地 ZIP 或 S3 兼容存储备份，支持 Cron 定时、保留策略与备份还原。
