## 2026-10-13 工具菜单、2FA 与 NATAPP

- 左侧新增「工具」入口，卡片分别进入 2FA 和 NATAPP。2FA 支持 Base32 密钥与 otpauth TOTP 链接，实时显示验证码、倒计时和进度，支持复制；密钥只保留于当前页面内存，不上传或持久化。
- NATAPP 支持多个隧道配置、启停和脱敏日志。首次先添加 authToken，再按 macOS Intel／Apple Silicon 或 Windows x86／x64 下载官方客户端；当前适配 3.0.5，Windows ARM64 暂不支持。安装信息仅解析官方脚本字面值，不执行远程脚本。
- 隧道列表增加访问地址与本地映射，来自当前运行的 `STAT status=online` 日志字段 `forwarding`／`local`，支持时间戳、分块输出与终端颜色码；只缓存当前运行地址，停止／退出／重连清除，新运行与工作空间隔离。长地址自动换行，启动图标为绿色、停止图标为红色，适配浅深色主题。
- 下载错误处理：官网对错误格式的 Token 会返回 HTTP 200 错误脚本，现已识别并提示正确的 16 位隧道 authToken，保存／安装前校验格式；字面解析兼容 Shell／PowerShell 的引号、注释和 BOM。失败或异常退出归位安装状态，前端废弃迟到读取并恢复重试按钮，保留错误原因。
- authToken 通过现有加密层存于工作空间数据库，不回显明文。安装包、客户端、日志及每次运行目录均位于配置数据目录的 `tools/natapp`；直接启动进程，以各次运行目录为工作目录。临时私有配置在停止／退出后清理，应用启动清理异常退出遗留。
- 隐藏到托盘继续运行，真正退出应用时回收进程，重启不自动启动。数据目录迁移同步复制客户端与日志并校验，迁移／恢复期间禁止启停竞态；常规备份保留数据库中的密文配置，不包含工具包、日志或临时配置。

## 3. 数据与安全

默认目录严格使用 `~/.perch`。固定 `bootstrap.json` 保存实际 dataRoot；工作空间定位及业务文件在所选目录。SQLite 是业务权威来源，原件按 SHA256 管理。

schema 6 将模型 API Key、禅道连接（含账号与历史）、邮箱账号及 CalDAV 配置加密存入 SQLite，模型密钥仍使用 `provider_credentials` 专用表。禅道令牌、邮箱/日历密码与 MCP 认证配置统一写入独立本地 AES-256-GCM 凭据库，不再访问系统钥匙串；旧钥匙串凭据需重新输入一次。普通实体接口仍拒绝顶层凭据字段，快照和历史不返回 API Key 或密码。

随机主密钥保存在本机应用数据目录并与密文分开，备份仅包含数据库密文、不携带主密钥及独立登录凭据。schema 6 打开与恢复激活前校验本机主密钥，缺失或密文损坏明确失败，禁止静默重建覆盖；同机恢复及目录迁移继续使用原密钥，跨机恢复须先安全迁移原本机主密钥。已有明文数据库在事务内升级，清理空闲页/WAL，原有明文备份不自动改写。本节为当前存储实现，前文历史验收中的 Keychain 描述不再适用。

迁移采用复制、校验、切换，源目录保留。备份使用 SQLite OnlineBackup、附件哈希清单和原子发布，不覆盖已有目标文件。恢复只接受空目标目录，拒绝目录穿越和超量包。数据表变更需继续增加版本化 migration；不能直接修改已发布 migration。

解析限制：单个文件 30 MB，解析并发 1，Java 堆 512 MB，60 秒超时，正文 16 MB 上限。关闭外部解析器与 OCR；扫描 PDF 无正文时显示需要文字识别。API 请求拒绝重定向，错误不回显远端凭据正文。
