# 本地加密凭据库、AI 用量与本机技能领域规则

修改 `src-tauri/src/credential_vault.rs`、`src-tauri/src/storage.rs`（加密与迁移）、`src-tauri/src/password_vault*`、`src-tauri/src/app_credentials.rs`、`src-tauri/src/integrations.rs`、`src-tauri/src/streaming.rs`、`src-tauri/src/local_skills.rs`、`src/features/Chat.tsx`、`src/features/PasswordVault.tsx` 前必须阅读并遵守本规则。

## 1. 本地加密凭据库与备份边界
- macOS / Windows 统一使用本地加密凭据库（AES-256-GCM），Token／登录密码／邮箱／S3／应用凭据／密码库等按工作空间与逻辑命名空间（AAD）严格隔离；不再读写系统钥匙串。
- 随机本机主密钥独立于工作空间与备份保存，禁止硬编码密钥、禁止写入日志/源码/错误详情或模型上下文。备份包仅包含数据库密文与受管附件，不携带本机主密钥或独立登录凭据。
- 跨进程文件锁和同目录原子替换保护凭据容器写入；缺主密钥、权限错误或密文损坏必须明确报错，绝不作为空数据静默覆盖。
- Schema 6 加密旧数据库中的模型密钥、账号配置及关联历史；测试仅使用临时目录与模拟凭据，绝不触碰本机真实凭据目录。

## 2. AI 会话流式输出与用量统计
- AI 消息用量仅取供应商真实返回值，`usage` / `durationMs` / `finishedAt` 随消息保存；缺失数据不估算、不补零。
- 流式用量为累计快照，不能逐帧相加；耗时使用单调时钟（`Instant`）计量，界面展示时间使用完成时间（`finishedAt`）。
- 外部网页、知识库导入文档、邮件正文及技能内容均视为不可信数据，不作为系统指令执行；前端渲染 Markdown 外链须经受控系统浏览器打开，禁止主窗口直接跳转到外部站点。

## 3. 本机技能扫描与编辑权限
- 本机技能读取只扫描声明的技能目录，严格限制目录深度、文件数量和单文件大小，绝不执行技能内脚本或内容。
- 按来源路径去重，新扫描导入的外部技能默认停用；重复扫描须保留用户已有的编辑内容与启停状态。
- 仅栖点自建或文件导入技能允许编辑和删除；外部目录扫描来源技能只读（仅允许启停）。后端必须以数据库已持久化来源为准阻止内容修改、来源清除和删除，扫描导入与补来源走专用内部入口。
- 聊天加载技能时必须实时核对当前技能表中的启用状态与存在性，不能让历史会话快照绕过技能停用或删除。
