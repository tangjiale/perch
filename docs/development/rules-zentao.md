# 禅道（ZenTao 22.0）与任务看板领域规则

修改 `src-tauri/src/zentao*`、`src-tauri/src/local_bugs.rs`、`src/features/Work.tsx`、`src/features/Bugs.tsx`、`src/components/Zentao*`、`src/components/TaskRichTextEditor.tsx` 前必须阅读并遵守本规则。参数细节另见 `docs/compatibility/zentao-22.0.md`。

## 1. 状态映射、排期与看板排序
- 禅道远端状态与本地状态分字段保存。任务四态 `todo`／`doing`／`suspended`／`done`，映射 `wait↔todo`、`doing↔doing`、`suspended↔suspended`、`closed↔done`；拖到已完成回写禅道 `closed`。项目和 BUG 使用各自状态。
- 任务只用 `schedule.start/end`，不再读写独立 `dueDate`；执行 `begin/end` 映射全天排期，结束日包含当天（存储层采用排他边界）。过期、统计及托盘按结束时间计算，无结束日期不判断过期；过期标签使用独立红色样式并兼容深色模式；已完成任务不显示过期且不计入逾期统计，其他状态仍按结束时间判断。项目自身 `dueDate` 不受此规则影响。
- 看板拖拽经 `save_task` 传临时 `boardBeforeId`（`null` 为列尾）；该字段不入库或远端 patch，目标列在单事务中按 `1024` 间隔重编号，同值按 ID 字符串升序。禁止恢复为单项取浮点中点；同列拖拽不回写禅道，跨状态保留远端校验与失败提示。

## 2. 执行同步、创建与回写
- 禅道仅同步 Token 当前账号的 `involved` 项目和 `PM.account` 匹配的执行（含本人负责的 `closed` 执行并映射已完成参与统计）；v1 执行需 `fields=PM`，身份或筛选核验失败不得回退全量。项目 PM 与执行 PM 分别保存，不能用项目负责人替代执行负责人筛选。禁止查询执行下任务或独立任务目录。
- 禅道同步按实际 API 分页元数据结束；22.0 越界会回第一页，不能只等空页或忽略重复。成功同步按连接原子清理失效工作项，失败不清理。
- 禅道定时同步由原生后台调度，`syncIntervalMinutes` 默认 `5`，`0` 为关闭；自动与手动同步共用连接锁，按工作空间 `generation` 隔离，成功通过 `zentao-updated` 刷新界面。失败保留缓存并等待完整周期；后台刷新不得重置未保存的连接表单。
- 禅道执行通过 `save_task` 统一回写名称、备注、状态和排期；本地任务仅本地保存。新任务关联禅道项目时 `save_task` 创建远端执行后落库，已有本地任务不追溯转换。
- 22.0 创建执行必须向 `POST /executions` 同时传 `project` 查询参数和 JSON 字段（同一个远端项目 ID；入口 param 只读 GET，会覆盖正文项目值）；测试须核验真实请求行及正文，禁止仅测试 payload。22.0 v1 按项目模型派生迭代，默认 `short`、`wait`、当前账号 PM，要求完整全天排期；不创建执行子任务。草稿 ID 必须稳定，持久记录 POST 提交意图，未知结果不重放；先核验返回内容再保存远端关联，并保证后续同步不重复导入。
- 禅道回写需核对远端身份、关联及版本冲突；先确认远端更新成功再保存本地，不把超时或部分失败显示为成功，不自动重试结果不明的写请求。测试使用模拟 HTTP 和临时库，不改真实禅道数据。

## 3. BUG 同步与流转
- BUG 使用独立缓存与 IPC，按 Token 当前账号的 `assignedTo` 严格筛选，不受个人项目范围限制，不混入任务。22.0 使用 v1 产品分页和 BUG 接口；状态流转按官方 action 路径处理，禁止猜测 v2 接口。完整读取成功后按连接原子替换缓存；写回核验身份、远端冲突与返回状态，不自动重放结果不明请求。BUG 统计为当前缓存样本，日期使用远端业务日期。
- `BUG.projectId` 是禅道远端项目 ID；项目筛选与项目页 BUG 统计按 `connectionId + Project.remoteId` 关联，不使用本地项目 ID 或名称匹配。
- BUG 的显式 `null` 指派人表示非本人，字段缺失须报错。仅本人已确认关闭的缓存可凭 `lastAssignedTo` 在同步清理前重新激活，仍检查远端版本；禁止借此放行转派或他人关闭。激活未指定影响版本时沿用刚读取的远端版本，不默认改成 `trunk`。

## 4. 认证续登与富文本附件
- 禅道配置持久记录 `authMode/loginAccount`；回显接口只返回匹配连接的已保存密码标志与 HTTP 许可布尔值，禁止返回密码／令牌。密码掩码仅为固定占位，普通保存不提交掩码或重新登录；主动修改才输入新密码，关闭记住仍可保留非秘密账号偏好。
- 自动重新登录仅在用户启用记住凭据后进行；密码与 HTTP 授权策略仅进本地加密凭据库的独立命名空间。读取请求遇明确 `401` 最多续登一次，失败暂停；`403`/超时不续登，`PUT` 不自动重放。普通修改保留凭据，关闭记住或更换手动令牌清除凭据，备份不携带密码。
- 任务备注富文本须清理不可信 HTML；富文本编辑器切换 `editable` 不得触发内容更新，未编辑备注保持原始 HTML。禅道描述冲突比较仅规范化经核验的同站附件 `src` 表示，不忽略正文或其他属性变化，不绕过远端冲突保护。
- 禅道图片仅通过已核对执行/BUG 引用的文件 ID 经原生 Token 接口读取，禁止代理任意地址。22.0 图片上传使用 v1 `files` 的 `imgFile` 字段，不自动重放未知结果；预览 `data URL` 不回写禅道，删除仅移除描述引用。
