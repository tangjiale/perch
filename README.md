# 栖点 / Perch

## 宣传主页

栖点宣传主页：<https://tangjiale.github.io/perch/>。主页展示四态任务与提醒、禅道项目和 BUG、钉钉日历、AI 聊天、工具箱及数据备份，并提供 macOS Apple Silicon 与 Windows x64 下载入口。打开页面或回到页面时直接查询 GitHub 最新正式 Release，可见页面每 5 分钟复查，下载链接取自实际发布资产。实时查询失败时回退同源清单并明确显示“最近发布记录”，两个来源都不可用时仍可前往最新 Release。

主页源码位于 `docs/`，官网文件推送到 `master` 或正式 Release 发布成功后，由 GitHub Actions 自动部署到 GitHub Pages；每次部署从最新公开 Release 获取并校验版本清单，不再依赖机器人提交触发部署。也支持在 Actions 中手动运行“发布宣传主页”。部署仅上传官网文件、图片与视频资源，不公开项目内部文档。仓库 Settings → Pages 的 Source 选择 **GitHub Actions** 即可启用，无需购买域名。自定义域名可在 Pages 设置中绑定，后续只需按 GitHub 提供的 DNS 记录配置即可。

主页提供 **软件操作讲解视频**：从首页“观看操作演示”进入，全程展示栖点软件内的菜单点击、任务创建与排期、状态修改、日历、AI 输入、汇率换算和备份入口，配合局部放大、中文旁白与同步字幕。可按章节跳转或下载 1080p MP4，默认不自动播放、不预加载大视频。演示使用隔离内存数据，外部服务需自行配置，钉钉日历与待办只读；画面不作为原生持久化或远端服务验收证据。可编辑的 Remotion 工程、配音来源与复现步骤见 [视频说明](video/README.md)。

主页产品截图由当前 Tauri React 应用界面生成，使用匿名示例数据，不包含个人工作空间信息。更新截图时应从当前 `src/` 界面重新截取，不使用 `ui/` 下的历史原型图片。

可复用的隔离演示入口为 `tests/promo.html`：运行 `npm run dev` 后访问 `http://127.0.0.1:1420/tests/promo.html`，按真实应用路由切换，在 1440×960 窗口截取 `docs/assets/screenshot-*.png`。该入口只用内存模拟 IPC，拒绝未声明命令，不读取真实工作空间或连接外部服务；演示截图不能替代原生集成验收。替换图片后同步更新官网资源版本参数，避免浏览器沿用旧图。

然后打开 <http://127.0.0.1:4173>。修改 `docs/index.html`、`docs/styles.css` 或 `docs/main.js` 后重新刷新页面即可。

## S3 备份与还原

进入 **设置 → 数据与备份**，填写 S3 端点、区域、存储桶、上传目录（Key 前缀）、Access Key ID 和 Secret Access Key。支持 S3 通用协议的对象存储；Cloudflare R2 的区域通常填 `auto`，AWS／OSS 等按服务商提供的区域填写，MinIO 等自建服务可开启“强制路径风格”。端点不包含存储桶；上传目录下自动按工作空间 ID 隔离备份，避免不同工作空间相互清理。密钥在独立本地凭据库加密保存，绑定端点／区域／存储桶，不回显也不进入备份；普通保存留空保留，切换目的地必须重新填写两项密钥。

- **测试连接**：以当前表单只读检查指定目录的列举权限，不上传测试文件；写入和删除权限在实际备份／保留清理时验证。保存后点击“立即备份”上传完整 ZIP；有未保存修改时先保存，失败保留表单。
- **定时备份**：启用后使用五字段 Cron（分、时、日、月、周），例如 `0 2 * * *` 为每天凌晨 2 点，`0 */6 * * *` 为每 6 小时。按本机时区由原生后台执行，关闭窗口留在托盘时仍有效；电脑休眠唤醒后最多补一次已到期备份，完全退出期间不执行，重新启动不追补离线任务。界面显示下次执行时间。
- **备份进度**：点击“立即备份”后立即生成一条记录并显示转圈；记录按准备、数据库备份、文件打包、计算校验值、上传、云端核验更新。数据库进度按实际页数、打包／上传按实际字节显示各阶段百分比。发送完正文后显示“等待云端确认”，确认远端对象存在且大小一致才成功；不把网络缓冲进度当作云端完成。打包在原生后台线程执行，关闭设置页不会取消备份。
- **下载备份**：成功记录的 ZIP 保存在配置的 S3 存储桶，本地上传暂存文件会在核验成功后清理。点击记录后的“下载”，选择本地保存位置；下载中显示忙碌状态，完整下载且大小匹配后才保存最终文件，不覆盖已有文件。下载只保存 ZIP，需要恢复时可使用“从文件还原”。
- **待确认与重新上传**：“待确认”表示网络断开、超时或服务端异常导致结果不明。点击该记录的“核验结果”，云端文件存在且大小一致会转为成功；未找到则转为失败，有本地 ZIP 时提供“重新上传”。重新上传前再次核验，已存在时只确认成功，不覆盖；核验失败或文件大小不符时拒绝重传。旧版本记录没有保留的本地 ZIP 时提供“重新备份”，重新打包为新记录。明确的 HTTP 403 等拒绝直接标记失败，并保留脱敏原因。
- **备份记录**：显示文件名、时间、大小、触发方式、月度归档和执行状态，刷新可核对当前工作空间目录。失败 ZIP 暂存在当前数据代的 `staging/s3-backup/`，重启后可继续核验／手动重传；成功后清理对应暂存文件，暂存目录不进入备份。未知结果不会自动重传，仅成功记录可还原。
- **还原**：选择记录并确认后，自动下载、校验清单／哈希／数据库，再恢复到原目录同级的新目录并切换。原目录保留，校验失败不切换；也可继续使用“导出完整备份”和“从文件还原”。备份包含数据库、加密配置与文档原件，不包含本机主密钥或独立登录凭据；跨机还原仍需原本机主密钥。
- **保留策略**：默认普通备份保留 14 天、最多 10 份；任一值为 `0` 表示不按该条件清理。仅在新建或重新上传成功并完整读取记录后清理本工作空间、符合栖点命名规则的旧普通备份，其他文件不受影响。启用月度归档后每月首份成功备份长期保留；关闭只停止新增归档，既有归档继续保留。单独点击“核验结果”不触发远端保留清理。

当前使用单个 ZIP 上传，最大 2 GiB；需配置列举、读取、写入权限，启用保留清理还需删除权限。网络请求不跟随重定向，不自动重试结果不明的上传。配置与记录复用 SQLite settings 加密存储，不增加数据库版本或扩大 Tauri 权限。验证使用临时数据库、本地模拟 S3 和隔离界面；真实云服务、系统休眠与 Windows 原生交互需要在目标环境验证。

## 产品介绍

栖点（Perch）是一款面向个人工作的桌面工作台，把每天要做的事、项目推进、禅道执行与 BUG、日历、邮件和常用工具放在同一处管理。它帮助你快速确认今天该做什么、事项卡在哪里，以及下一步应该打开哪个工作入口。

### 名称含义

“Perch” 的英文含义是“栖息处、停留的位置”，也可以指鸟停留的枝头，发音接近“珀奇”。在栖点中，“栖点”代表个人任务、项目、日历、知识库和 AI 助手汇聚的工作落脚点；“Perch”是应用的英文品牌名，不是某个具体功能名称。中文界面以“栖点”为主。

- **任务与项目**：管理本地任务、项目和排期，以列表、看板和日历查看进度；可按任务开启到期系统通知，选择到期时或提前提醒；可连接禅道，同步并在已确认后回写本人参与的执行与 BUG。
- **工作信息汇集**：集中查看钉钉 CalDAV 日历、多个邮箱、常用应用和工作统计，避免在多个页面之间反复切换。
- **AI 与知识辅助**：按需配置模型、Agent、技能和知识库，用于聊天、整理和辅助日常工作；模型请求只会在用户发送消息时发起。
- **本地优先与安全**：工作数据保存在本机 SQLite；模型 API Key、登录账号、密码和令牌均加密保存，不再使用系统钥匙串。

已开始按确认的架构开发，当前提供 **Tauri 2 + React + Rust + SQLite 的 macOS Apple Silicon 0.1.0 开发版本**。它使用真实本地数据库、原生文件选择、本地加密凭据库和网络适配器。完整验收状态及架构差异见 [实现与验证记录](docs/IMPLEMENTATION.md)，不能将开发版本等同于全部架构工作包已完成。

## 运行与构建

要求 Node.js 22+、Rust；macOS 需要 Command Line Tools，Windows 需要 MSVC 构建工具与 WebView2。解析运行时支持 Apple Silicon macOS 和 Windows x64，随应用打包，无需全局 Java 或 PostgreSQL。

```bash
npm ci
npm run runtime:prepare
npm run tauri dev
npm test
cargo test --manifest-path src-tauri/Cargo.toml --lib
npm run tauri build -- --bundles app,dmg
```

macOS 安装包在 `src-tauri/target/release/bundle/dmg/`，App 在 `src-tauri/target/release/bundle/macos/`。目前没有 Developer ID 签名或公证。版本号已接入检查、下载和安装更新；正式更新源由 Tag 工作流注入，普通本地构建未配置更新源。

### macOS 首次打开未签名版本

当前 macOS 安装包尚未配置 Apple Developer ID 签名和公证。首次从浏览器下载后，系统可能提示“栖点.app 已损坏，无法打开”。请确认安装包来源可信，然后将应用拖入“应用程序”目录，在终端执行：

```bash
xattr -cr "/Applications/栖点.app"
open "/Applications/栖点.app"
```

也可以在 Finder 中右键点击应用，选择“打开”，并在系统提示中确认。正式发布版本配置 Developer ID 签名和公证后，不需要执行上述操作。

推送 `vX.Y.Z` Tag 后自动构建 macOS Apple Silicon 和 Windows x64，并在双平台成功后统一发布 Release。中文提交约定、多个 commit 的更新说明汇总、首次签名配置见 [发布与在线更新](docs/RELEASE.md)。

默认数据位置为 `~/.perch`。在设置的“数据与备份”中更改路径、备份和恢复。模型 API Key 与账号配置以密文保存在工作空间数据库；禅道令牌和邮箱密码等存于本机独立加密凭据库。完整备份只包含数据库中的密文，不包含主密钥和独立登录凭据；同机恢复可继续使用，跨机恢复需要原本机主密钥。

`npm run dev` 提供 React 浏览器界面预览，端口默认 1420；业务数据写入只能在桌面 App 内完成。通过 `npm run dev` 或 `npm run tauri dev` 从本地源码启动时，侧栏、版本弹窗与“关于”页统一显示 `dev`；正式构建显示发布版本号。原 `ui/` 设计预览继续保留。

## 当前功能入口

应用内弹窗统一禁止点击外部遮罩、内部空白或按 Esc 关闭，避免填写到一半丢失内容；手动退出使用右上角关闭按钮。保存成功及明确点击取消仍按各表单流程处理，处理中受保护的弹窗会禁用关闭按钮。嵌套图片预览同样使用右上角关闭，关闭后回到原表单并保留输入；下拉和右键菜单可按 Esc 收起菜单。

在“设置 → 禅道连接”中可直接修改已有连接的服务地址，适用于同一禅道实例更换域名、IP、端口或安装路径；连接 ID 及已有项目、执行关联保持不变。修改后需重新输入账号密码登录，或填写新地址的访问令牌；HTTP 地址需重新勾选登录许可。旧密码和令牌不会自动用于新地址，保存失败时保留原连接和凭据。仅调整尾部斜杠等规范化后等价的地址不要求重新认证。

禅道项目列表与项目详情显示“计划开始日期 / 计划结束日期”，分别同步项目自身的 `begin / end`，不使用执行排期推算。日期为空或无效时显示“未设置”；已有连接升级后同步一次即可补齐。禅道项目计划日期只读，本地项目原有截止日期保持。

项目页采用紧凑五列布局：项目／负责人、计划日期、任务进度、BUG 进度、操作。状态标记紧邻名称，长描述最多两行，无描述不占行；禅道 HTML 描述转为安全纯文本，保留原描述供详情查看和编辑。任务进度按当前关联任务展示待做、正在做、已挂起、已完成的数量与分布，不代表远端项目整体进度。点击项目名称或任务进度查看关联任务；BUG 进度展示总数、待解决、已解决、已关闭及状态分布，点击进入该项目的 BUG 列表。本地项目显示“未关联禅道”。右侧保留添加任务和编辑项目入口；支持深浅主题及窄窗口。

任务看板从左到右依次为待做、正在做、已完成、已挂起。已完成任务在看板和列表中使用灰色标题及删除线显示，弱化来源和辅助信息；仍可打开详情和拖动恢复状态，已完成后不再显示过期标签，也不计入逾期数量；重新打开后按结束时间判断。

任务看板卡片底部分两行显示开始和结束日期；定时任务显示具体时间，全天任务显示包含当天的实际结束日，缺失日期标为“未设置”。任务看板支持拖动卡片右上角手柄，在同一状态列排序，或移动到待做、正在做、已挂起、已完成任意列的顶部、中间和末尾；拖入两张卡片之间时显示插入空位，下方卡片自动让位。松手后以明确插入位置原子保存本地顺序，支持同排序值任务，重新打开及禅道同步后保留已有顺序。保存中暂时禁用拖动，失败保持原位置；可撤销最近一次成功拖动。同列排序不请求禅道，跨状态的禅道执行仍需远端身份、权限和状态变更核验，失败不会假装成功。

禅道任务卡片右上角与项目名称旁新增“在禅道中打开”图标，在默认浏览器进入对应执行／任务或项目详情；本地任务与项目不显示。链接保留禅道安装子目录且不携带令牌，浏览器未登录时需先登录禅道。

**在禅道打开任务**：禅道来源的任务详情顶部提供“在禅道打开”，与 BUG 详情保持一致。点击后通过系统浏览器打开该任务关联的禅道执行详情，沿用所属连接的地址与安装子目录；不会触发表单保存。本地任务不显示此入口。

**任务详情中的指派信息**：打开已同步的禅道执行，在备注上方的禅道说明区域查看指派人、指派时间和创建人。桌面应用按需只读查询执行操作历史，以最近一次负责人变更的操作者为指派人；先核验当前账号和所属项目，不查询执行下的任务。没有可核实的负责人变更记录时显示“未找到指派记录”，创建人单独展示；读取失败可重试，不影响编辑和保存任务。浏览器预览不读取真实禅道信息。

“在禅道管理”、应用卡片及更新日志通过系统默认浏览器打开 HTTP/HTTPS 网页，支持内网 IP、端口和子路径。Tauri 同时需要打开命令权限与 URL 范围；本项目已配置网页范围，不开放本地文件 URL 或任意指定程序。若旧安装包提示 `Not allowed to open url`，安装修复版并完全退出旧进程后重新打开，权限配置不会热更新。

打开禅道网页和连接认证是独立动作：网页跳转不自动向栖点授权 API；连接认证直接在禅道设置页的“账号登录”或“访问令牌”中完成。
禅道设置采用单连接页面，直接展示连接名称、地址、API 版本和认证表单，不再通过连接列表打开配置弹窗。顶部保留“同步项目与执行”和“在禅道管理”；未保存连接时按钮禁用。已有连接配置直接载入，保存仍更新原连接及关联数据。

**令牌失效自动登录**：在“设置 → 禅道连接 → 账号登录”中勾选“记住登录凭据，令牌失效后自动重新登录”，输入账号密码并登录保存一次即可启用。日常拉取与修改仍复用令牌；读取请求明确返回 401 时才用本地加密凭据库中的凭据自动获取新令牌，最多尝试一次。自动登录失败后暂停，需重新配置；403 权限不足和网络超时不触发登录。写入请求不自动重放，结果不明先同步核对。密码仅进入本地加密凭据库，不进入业务数据库和备份；取消勾选保存或换成手动令牌会清除记住的凭据。

**账号配置回显**：保存后记住所选登录方式和账号，重新打开时恢复。账号与密码输入框对齐；已记住的密码只用固定星号掩码显示，原密码不会返回界面。点击“修改密码”才进入新密码输入，点击“保留原密码”取消修改。未修改密码时保存配置会复用已有令牌及凭据，不重新登录。HTTP 选项根据同一连接在本地加密凭据库中保存的许可状态恢复，不跨地址或账号复用。关闭“记住登录凭据”会清除已保存的密码，但保留账号和登录方式方便下次填写；未记住或换设备后不显示虚假的已保存密码。

**个人同步范围**：每次同步先通过 `/api.php/v1/user` 识别 Token 所属账号，再使用 v1 `projects?involved=1` 查询禅道“我参与”的项目（创建者、项目负责人、团队成员、干系人或白名单成员）。全局执行目录请求 `fields=PM`，只导入这些项目中 `PM.account` 与当前账号一致的执行（包含已关闭），不把“有权限查看”当作“与我相关”。没有负责人或负责人不是本人则排除；账号识别或负责人字段核验失败时中止，不回退到全量同步。即使连接选择 v2，这条个人同步链路仍使用具备明确筛选语义的 v1。不会自动重新同步，需点击同步按钮。

**只同步执行**：不请求执行下的具体任务，也不读取独立任务目录。下次成功同步会通过当前连接的工作项差集清理此前导入的禅道任务；自建任务和其他连接不受影响。

**新建任务关联禅道项目**：在“新建任务”选择禅道项目，保存时会在该项目创建一个禅道执行，成功后自动保存执行编号、负责人和项目关联；后续编辑、拖动状态、日期调整复用执行回写流程。选择自建项目或不关联项目时仅创建本地任务。已有本地任务改关联项目不会追溯创建执行。

默认按禅道“添加执行”简洁版：短期迭代、初始未开始（工作台显示待做）、当前 Token 账号为执行负责人及团队成员；任务名称对应执行名称，备注对应执行描述，计划开始／结束日期必填，结束日包含当天。选择禅道项目会自动切换全天日期，保留已填日期；没有开始日期时默认今天。关联产品、计划和可用工作日不自动填充，执行代号使用稳定草稿标识自动生成，兼容开启代号的实例。22.0 v1 根据项目模型派生执行方式，因此仅支持可创建迭代的 Scrum／融合敏捷项目；其他模型、已关闭或未开启多执行的项目会提示在禅道中创建后再同步。

创建前核验项目、当前账号、排期与本地版本。POST 不自动续登重放；提交记录持久保存在工作空间，阻止同一草稿重复提交。超时或结果不明时，先同步并在禅道核对是否已创建，不要立即重新新建。远端成功但本地保存／页面刷新失败会明确提示；不会显示为普通本地任务创建成功。

**禅道同步**：进入“设置 → 禅道连接 → 同步项目与执行”。按服务端分页信息读完相关项目与全局执行目录，再核验负责人、状态和项目关联。读取失败时不发布、不清理旧数据；成功后原子保存项目及执行，清理不再符合范围的旧工作项。状态和排期按禅道更新，备注保留。本地模拟验证不等于真实账号验收。

## 邮件与多邮箱设置

在 **设置 → 邮箱设置 → 添加邮箱** 中填写显示名称、邮箱地址、发件人名称及 IMAP / SMTP 参数。预设仅填写服务器地址，可继续修改；用户名留空时使用邮箱地址，发件人名称留空时使用显示名称。先在邮箱服务商处开启 IMAP / SMTP；QQ / Foxmail、网易及开启双重验证的邮箱通常需要邮箱授权码或应用专用密码。账号配置与收发凭据均在本地加密保存，收发密码按用途独立隔离；新邮箱的发信凭据留空时使用收信凭据，编辑现有邮箱时留空保留原值。仅支持 SSL/TLS 与必须升级加密的 STARTTLS，不降级为明文。

左侧 **邮件** 菜单提供：

- 多账号折叠与切换；收件箱、已发送、服务器草稿、已删除、垃圾邮件、归档和其他服务端文件夹；另提供本地草稿与发送记录。
- 1440px 三栏阅读；窄窗口自动切换为列表 / 阅读区，通过返回按钮回到列表。支持当前文件夹缓存搜索、未读和星标筛选。
- 阅读时标为已读、切换已读 / 未读及星标、移动至其他文件夹或已删除。移动依赖服务器支持 IMAP MOVE，不支持时明确提示，不执行可能影响其他邮件的全局清除。
- 写邮件、回复、回复全部、转发正文；收件人 / 抄送 / 密送使用逗号分隔；附件添加、移除及下载。转发正文不自动附带原附件，如需转发附件可先保存再选择。
- 本地草稿需点击“保存草稿”；点击“发送”才通过 SMTP 投递。发送副本尝试保存到服务器的已发送文件夹。SMTP 接受、发送中和结果未确认的记录可在“发送记录”中查看；不确定结果不会自动重发，需先核对网页邮箱或与收件人确认。SMTP 接受不代表收件人已阅读。
- 有 HTML 正文的邮件默认显示安全排版，可切换纯文本；纯文本邮件直接显示正文。HTML 正文经过清理并放入无脚本沙箱，纯文本提取会排除样式和脚本内容，并保留段落、换行与表格间隔。已有缓存正文重新打开即可应用修复，列表摘要在下次同步时更新。外部图片、跟踪资源、活动内容与正文内导航被禁用，附件由用户选择保存路径。

**未读刷新**：每个账号默认每 1 分钟检查，可选 3 / 5 / 15 分钟。原生后台调度与页面独立，隐藏到托盘仍继续；退出程序、设备休眠或网络断开时不能收信。菜单角标汇总已启用邮箱的收件箱未读数，超过 99 显示 `99+`；以服务端 UNSEEN 统计为准，不受缓存条数限制。后台事件刷新页面，同时每 15 秒重读本地未读统计；实际新邮件发现时间受检查间隔及服务器耗时影响，并非 IMAP IDLE 推送。

**缓存与兼容范围**：当前同步每个打开文件夹的最近 200 封邮件，自动检查同步收件箱；首次加载后复用已缓存正文。邮件列表支持主题、发件人与摘要搜索，搜索中的 `%`、`_` 和反斜杠按普通字符匹配；已修复查询转义导致已缓存邮件报“邮件数据库操作失败”的问题，无需清空缓存。单封上限 25 MB、每次最多 100 MB、最多 200 个文件夹，超限会提示。发送附件最多 20 个、合计 18 MB。密码 / 授权码认证已实现，OAuth、POP3、Exchange、邮件规则与远程草稿双向同步尚未实现；仅允许 OAuth 的邮箱需另行适配。

邮箱元数据、收信原文及附件缓存进入现有 SQLite，通过新增 migration 002 升级，随工作空间备份与迁移；当前备份为 schema 6，兼容 schema 1–5 旧备份。邮箱账号配置加密写入数据库，密码及授权码保存在独立本地加密凭据库、不随备份迁移；跨机恢复需原本机主密钥，再重新填写邮箱密码。草稿附件引用选择时的原文件，发信前须保持原路径可读取。移除账号只清除本地邮箱配置和缓存，不删除服务器邮件。

## 关闭行为与系统托盘

桌面 App 的 BUG、任务备注及大图预览提供中文图片右键菜单：“复制图片”写入系统剪贴板，可粘贴到其他应用；“下载图片”选择保存位置，保留原始图片格式。仅操作已加载的 PNG/JPEG/GIF/WebP 图片，单张不超过 12 MiB、单边不超过 16384 像素且总计不超过 4000 万像素；动图复制首帧，下载保留动画。菜单显示操作结果或错误，取消保存不提示成功。WebView 默认右键菜单（包括邮件正文嵌入区域）统一禁用，保留文字选择、复制粘贴快捷键及系统托盘菜单。页面与内部滚动区域关闭边界回弹和滚动穿透，列表、聊天及邮件仍可正常滚动；浏览器预览保留浏览器右键菜单。

顶部全局搜索聚焦时，焦点描边沿包含搜索图标的完整圆角外框显示，兼容浅色、深色和键盘聚焦。

顶部栏显示系统本地时间的公历年月日、星期、时分秒和农历月日，每秒更新；恢复窗口时立即校准，跨日自动更新日期。日期、星期、时分秒和农历同一行分隔展示；农历使用独立的 lunar-typescript 计算，避免不同 WebView 的 Intl 中文日数差异导致缺失，不依赖联网；时钟独立刷新，避免每秒重绘整个工作台，兼容深浅主题和窄窗口。

- 悬停显示今日待办、正在做、逾期数量及最多三条任务摘要；每 30 秒刷新，鼠标进入时也更新。点击恢复主窗口，右键可打开任务待办或退出。macOS Dock 重新打开和单实例激活也能恢复隐藏窗口。
- 设备关闭偏好使用 Tauri 应用配置目录中的 `device-settings.json` 原子保存，不随工作空间切换。若托盘创建失败，会提示并允许正常退出，避免留下无法找回的隐藏窗口。

验证：邮件后端测试覆盖 MIME、IMAP UID / FLAGS / STATUS、密送、发送互斥及 SQLite 备份恢复；托盘测试覆盖偏好保存、任务摘要与日期边界。`tests/mail-browser.js` 通过隔离模拟 IPC 检查多邮箱、阅读、回复、草稿、发送与通用设置；未使用用户凭据、未发送真实邮件。真实邮箱 TLS / 认证、Mac 托盘交互与 Windows 桌面行为仍需安装后的原生验收。

## 拉取供应商模型

进入 **设置 → 大模型管理 → 添加供应商 / 配置 → 保存并拉取模型**。先保存当前名称、API 根地址、协议和密钥，再打开模型选择弹窗。API Key 留空保留已有数据库密钥；本地免密服务可留空。密钥通过 AES-256-GCM 加密后保存在本地 SQLite 的后端专用表中，重启后无需重复输入，也不会随工作空间快照或实体历史返回前端；完整备份只包含密文，解密主密钥不随备份导出。已有数据库明文密钥会在 schema 6 升级时加密，并清理数据库空闲页和 WAL 中的旧明文。旧版本已存于系统钥匙串的模型密钥不会自动读取，升级后需要重新输入一次，此后由本地加密存储持续保存。

- 支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages。目录请求为 API 根地址追加 `/models`；例如 `http://localhost:8000/v1` 对应 `/v1/models`。Anthropic 目录支持自动分页。
- 弹窗支持名称 / ID 搜索、全选当前筛选结果、清空选择与选中计数。已添加的模型显示标记且不能重复勾选。确认后一次性保存，按供应商与远端模型 ID 去重，不覆盖已有模型的配置。
- 目录通常没有能力信息，勾选后默认“文本”；请按实际能力选择“视觉”或“向量”。文本用于文字聊天，视觉用于图片与文字聊天，向量用于知识库。不根据名称推算向量维度；用于知识库前仍需确认供应商支持相应接口。
- 模型导入和模型编辑的类型采用直接可见的“文本 / 视觉 / 向量”三段式单选，点击即可切换，无需展开下拉浮层。先勾选待添加模型，再选择类型；支持键盘操作和浅深色模式。
- 模型列表的状态列提供启用 / 禁用滑块，点击直接保存；每行提供删除按钮，确认后移除本地模型配置。被 Agent 或知识库引用的模型需先解除引用才能删除；操作期间防止重复提交，保存失败会提示并保留原状态。
- 拉取失败可重试，空目录不能提交；保存成功但刷新失败时仅重试刷新。供应商配置变化或工作空间切换 / 恢复后，需要重新拉取目录。浅色与深色模式均使用现有玻璃弹窗和 GlassSelect。
- 不支持标准模型目录的服务仍可通过供应商卡片“添加模型”手动配置。非标准 OpenAI 分页会明确报错，不将首批结果当作完整目录。最多 5000 个模型、20 页，每页 2 MiB，单请求 20 秒、总拉取 60 秒；不跟随重定向。

验证：`cargo test --manifest-path src-tauri/Cargo.toml --lib provider_models` 覆盖本地 HTTP、认证、分页、错误和临时 SQLite 批量导入；`tests/provider-models-browser.js` 用隔离 iframe 模拟 IPC 验证界面流程。模拟验证不代表真实供应商已联调。

## 禅道负责人和执行范围

农历、节气、节假日及休／班标记在日历中始终显示，不增加左侧日历类型或开关；左侧仍只筛选个人任务和禅道执行。月历日期旁显示农历日数（初一显示月份）、传统节日或节气；日／周日期标题同步显示，小日历提供休／班角标。绿色「休」代表普通周末休息或官方放假安排，橙色「班」代表调休上班；年度调休安排优先，需要上班的周六／周日显示「班」。悬停可区分「周末休息」与节假日名称和说明。显示层只提供日期信息，不生成任务、不修改排期或参与任务统计。

月视图同一天默认展示最多 3 项，超出部分通过「+N 项」展开。未完成任务优先显示，已完成任务优先折叠；有剩余位置时仍可直接显示已完成任务。相同完成状态内继续按开始时间、持续时长等既有规则排序，钉钉日程按普通日程参与显示。

放假调休采用 lunar-typescript 内置中国大陆年度安排，当前完整覆盖 2002–2026；未收录年份显示农历、节气与普通周末休息，并提示调休数据尚未收录，不推算未来调休。2026 年数据已与[国务院办公厅通知（国办发明电〔2025〕7号）](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)逐日核对：9 月 20 日上班、9 月 25–27 日中秋放假、10 月 1–7 日国庆放假、10 月 10 日上班。内置数据离线可用，后续年度需随数据更新提供；当前不包含企业自定义假期或个人请假记录。

**定时自动同步**：在「设置 → 禅道连接 → 自动同步频率」配置并保存，默认每 5 分钟，可选 1 / 5 / 10 / 15 / 30 / 60 分钟或关闭。原生后台启动约 5 秒后执行首轮，随后从每轮完成时开始计时，自动拉取我参与的项目、我负责的执行（包含已关闭）及指派给我的 BUG。同步完成后自动刷新看板、BUG、总览和统计；最小化到托盘仍运行，退出应用或设备休眠时不执行。新连接和未配置过频率的已有连接默认启用每 5 分钟同步。

自动与手动同步共用连接锁，避免重叠请求；复用已保存令牌和既有 401 续登规则，不每轮账号登录。两类数据分别成功后更新缓存，失败保留该类缓存并等待下一周期，不连续弹窗；设置页可查看项目执行及 BUG 最近成功同步时间。后台刷新不会清空正在编辑的连接表单。定时器和设置已用模拟数据验证，真实禅道连通性仍取决于当前网络、账号权限和令牌状态。

**统一任务日期**：任务表单只保留开始、结束日期／时间与时区，移除独立截止日期。日历、过期标签、统计和托盘统一使用排期；没有结束日期时不自动判定过期。旧工作空间及旧备份会在升级时迁移：已有结束日期的排期保持不变，旧的独立截止日期不再参与计算；仅有截止日期的记录转换为该日期的全天排期。项目自己的截止日期不属于任务排期，本次保持。

总览“今日安排”和任务列表的“个人安排”展示完整起止范围：跨天全天任务显示如“10月12日 – 10月15日 全天”，结束日期为实际包含的最后一天；单日全天任务只显示当天，跨年范围补充年份。定时任务按排期时区显示起止时间，未设置结束日期时只显示开始日期／时间。

**已过期标签**：看板、列表、详情和日历事件使用红色文字及淡红背景显示“已过期”，兼容浅色、深色模式，已完成任务不显示；待做、正在做、已挂起任务按结束时间判断。仅使用排期结束日期／时间；全天排期的结束日已包含在范围中，到下一天才过期。没有有效结束日期不标记。页面每分钟及重新获得焦点时刷新标签；过期标记不会修改任务状态。

**看板状态与日历排期**：禅道“未开始 / 进行中 / 已挂起 / 已关闭”与本地“待做 / 正在做 / 已挂起 / 已完成”对应（wait↔todo、doing↔doing、suspended↔suspended、closed↔done）。鼠标拖动按实际指针落点识别卡片及状态列，支持从长任务列拖入空的“已挂起”“已完成”列；使用卡片右上角拖动手柄操作。拖动看板变更状态、编辑任务名称及备注、修改日期或拖动日历排期时，会通过官方执行编辑接口更新禅道；本地自建任务仍仅保存在本地。执行使用 begin / end，仅支持全天日期，修改排期需同时填写开始和结束日期，结束日包含当天。例如 9 月 8 日到 10 日，会在 8、9、10 日均显示。已关闭执行在后续同步时继续保留，并计入总览、项目任务分布及统计页的已完成数量。

已有任务在升级到 schema 8 时将“已关闭”归入“已完成”，保留任务编号、项目关联、修订号、历史与提醒记录；完成时间优先保留原值或原关闭时间，缺失时不补为升级当天。拖到“已完成”会在禅道关闭执行，后续同步仍显示已完成；拖到“已挂起”则回写 suspended。


**禅道回写结果**：远端更新成功后才保存本地并显示成功。权限不足、连接失败或数据冲突时显示错误；写入结果不明时不自动重试，应先重新同步核对。执行所属项目保持与禅道一致，个人优先级和看板排序仍为本地设置。拖动失败时看板保留错误提示；HTTP 401 表示令牌失效或认证被拒绝，可点击“重新登录禅道”，编辑原连接重新登录或更新令牌，同步后再拖动。HTTP 403 应检查当前账号执行查看与编辑权限。

修改执行排期时，先读取禅道当前的可用工作日；若原值超过新的日期跨度（包含开始和结束当天），仅将它缩减到新跨度，合法原值保持不变，不重新估算节假日。HTTP 400 / 422 或业务校验失败会显示可安全展示的具体字段原因，例如结束日期超出所属项目范围。失败仍应先同步核对远端结果，避免重复提交。

禅道同步补充：项目负责人从远端 PM 保存到项目的负责人字段；执行卡片显示执行负责人。执行要求 `PM.account` 为当前 Token 账号；包含已关闭执行，映射到工作台“已完成”，但仍不读取执行下的具体任务。下次成功同步会在同一事务移除当前连接中已不符合范围的旧工作项，保留自建任务、其他连接数据以及仍在范围内任务的备注（状态按禅道同步映射更新）。网络、权限或关联核验失败时整轮不发布，不会提前删除旧数据。

## 预置 Agent

首次打开包含此功能的版本，会为当前工作空间补齐五个助手：任务助手（拆解、优先级、阻塞与交付）、通用聊天（问答、写作和总结）、财务助手（预算、核对与报表）、法务助手（合同、条款与风险）、IT 助手（开发、排障和运维）。在“设置 → Agent”查看、修改或删除，聊天页可选择已启用的助手。

预置优先关联已启用供应商下的文本模型，其次选择视觉模型；没有可用模型时保持停用，需要在 Agent 配置中选择模型并启用。每个工作空间只初始化一次，不覆盖已有同 ID 助手，不恢复用户主动删除的预置，也不覆盖后续编辑。任务助手当前产出行动计划和交付内容，不会自动修改工作台或禅道任务；财务、法务和 IT 提示词要求明确依据和适用范围，不编造数据、条文或执行结果。

聊天消息采用“右侧用户气泡＋左侧助手正文”布局：自己的消息靠右，Agent 回复直接排版，不带气泡背景、边框或阴影，历史消息与流式回复保持一致；自己的气泡省去重复称呼，短消息保持一行；复制按钮位于气泡外，悬停或键盘聚焦显示。气泡随内容收缩，长文本换行，代码与表格在各自消息区域内滚动，兼容深浅主题。AI 回复正文底部集中显示复制、Token 用量、模型请求耗时和完成时间，移除回复右上角复制按钮；用量来自供应商实际返回；达到 1,000 tok 后以 K 为单位并保留两位小数（例如 7,460 → 7.46K tok），不足 1,000 显示整数，悬停仍可看输入／输出的精确明细。缺失用量显示“未提供”，历史消息缺失耗时显示“未记录”，不按文本长度估算。用量与耗时随消息保存，兼容 OpenAI Chat Completions、Responses 和 Anthropic Messages 协议。聊天输入区底部依次展示添加图片、模型选择和知识库选择，发送按钮位于右侧；窄窗口下工具栏自动换行，避免与输入框重叠。没有历史会话时输入框保持可编辑，首次发送绑定所选 Agent 与知识库。新建会话前检查 Agent、聊天模型及供应商是否可用；配置有误显示中文指引并保留输入。首次发送失败后复用已创建会话重试，避免重复生成空会话。

聊天输入区的模型下拉支持切换已启用供应商下的文本／视觉模型，选项显示模型名称和供应商。新会话默认使用所选 Agent 的模型，也可先选模型再发送；已有会话的选择独立保存，重新打开后继续使用，下次发送按新模型及其供应商执行。切换保留当前 Agent 的提示词、技能和聊天历史，全局 Agent 默认配置保持独立。生成、创建或保存模型选择期间禁止重复切换与发送，保存失败保留原选择和草稿。有未发送图片时需先移除图片再切换到文本模型；切换后历史图片仍保留在会话中，文本模型只接收历史文字。

## 视觉模型与图片聊天

在 **设置 → 大模型管理** 中将支持图片的模型类型设为“视觉”，然后在 **设置 → Agent** 中为助手选择该模型。进入聊天，选择该 Agent 或在输入区模型下拉中选择视觉模型，即可输入或添加图片，首次发送时自动创建会话，也可手动点击“新会话”；已有会话所用模型的类型修改也会立即生效。聊天中切换模型会更新当前会话的模型与供应商配置快照；Agent 提示词和技能等配置仍沿用会话快照，新建会话可采用最新 Agent 配置。

- 点击“添加图片”选择文件，或在消息框中粘贴图片。发送前显示缩略图、文件名，可逐张移除；支持纯图片或图文一起发送，发送失败保留草稿。
- 支持 PNG、JPEG、WebP、GIF，每条最多 4 张，单张最多 5 MiB、合计最多 12 MiB。后端核验真实文件签名和 Base64 数据；文本模型禁止发送图片，向量模型不能聊天。
- 支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 三种协议的图片请求格式；服务端模型本身必须支持视觉，修改类型不会为纯文本模型增加视觉能力。
- 图片保存在本地消息数据中，重启后仍能查看，随工作空间备份与恢复一起保留。对话上下文最多取最近 20 条消息，当前与历史图片合计最多 12 MiB，超限截断较早历史。
- 图片和文字会在点击发送时传给该会话配置的模型供应商。选择知识库但仅发送图片时不执行文字检索；附上文字问题后才会同时检索知识库。

验证：图片读取限制单元测试、模型类型与图片聊天浏览器模拟 IPC 测试、Rust 图片格式 / 三协议编码 / SQLite 重开历史图片测试。未使用真实供应商密钥进行视觉推理验收。

禅道 22.0 创建执行时同时在 URL 查询参数与 JSON 正文传入相同的远端项目编号，避免接口覆盖正文项目值后误报“所属项目不能为空”。新建任务的禅道执行说明默认收起，点击“所属项目”标签右侧的感叹号可展开或收起中性样式说明。创建禅道执行时会读取远端项目的计划日期，并在提交前检查任务日期是否超出项目范围。HTTP 400／422 会显示禅道返回的可安全展示的字段校验信息（例如名称、开始日期或结束日期），不会再把创建接口的这类错误提示为连接失效；非结构化响应不直接展示。创建失败保留表单内容，未知结果仍禁止自动重复 POST，需先在禅道核对。

## 工具

左侧 **工具**（`/#/tools`）以紧凑卡片展示 **2FA 验证码**、**NATAPP 内网穿透** 和 **汇率转换**，图标与名称同排；按可用宽度每行展示 3～4 个工具，窄窗口自动减为 1～2 列。

**汇率转换**（`/#/tools/exchange`）：输入金额并选择来源币种，可同时添加、删除或更换多个目标币种（最多 30 个，禁止重复）。来源和目标币种均支持下拉搜索，可输入中文名称或货币代码的部分内容进行匹配，代码不区分大小写；支持方向键选择、回车确认和 Escape 关闭。默认以 100 人民币换算美元、欧元、港币和日元，每行同时展示换算金额和 `1 来源币种 = … 目标币种` 的汇率。支持服务商提供的币种，金额变动立即在本机重新计算；金额不会发往外部。金额、来源和目标列表作为本机界面偏好按工作空间保存，不包含在数据库备份中。零金额可转换，极小非零结果明确显示低于最小货币单位，非法输入不计算。

汇率通过桌面端读取 [ExchangeRate-API](https://www.exchangerate-api.com) 的免费公开接口，无需密钥；为每日更新的参考汇率，非实时交易报价，实际兑换以银行或支付机构报价为准。页面显示服务商更新时间和本次获取时间，点击“刷新汇率”重新查询。应用内复用未到下次更新时段的汇率；刷新失败保留该来源币种的上次结果并提示失败，切换来源不会误用旧币种汇率。查询需要联网，浏览器预览不提供模拟汇率。

NATAPP 工具页标题下提供 [官网地址](https://natapp.cn/)，点击通过系统默认浏览器打开，方便管理隧道与获取 authToken。

**2FA 验证码**：输入 Base32 密钥或 `otpauth://totp/...` 链接，在本机生成验证码，显示进度条与剩余有效秒数，支持复制和清空。普通密钥默认 6 位、SHA1、30 秒；链接可指定 6／8 位、SHA1／SHA256／SHA512 和刷新周期。验证码根据系统时间自动更新，离开页面即清空密钥，不保存、不联网；不支持 HOTP 计数型验证码。

**NATAPP 内网穿透**：先“添加隧道”，填写名称和从官网隧道列表复制的 **16 位字母或数字 authToken**（不要填写账户 API Token），再点击“下载并安装 NATAPP”。可维护多个配置，分别启动、停止和查看输出日志；运行时编辑或删除需先停止。编辑已保存配置时，authToken 留空表示保留原值。安装按当前系统选择 macOS Apple 芯片／Intel 或 Windows 32／64 位官方客户端；当前核验版本为 3.0.5，Windows ARM64 暂无官方对应包。客户端下载通过 HTTPS 官方源进行，使用已保存隧道的 Token 获取安装信息，不执行官网安装脚本。Token 格式不正确或官网拒绝时显示明确原因；下载失败会退出安装中状态，可修正配置后重试，客户端完整落地并校验后才可启动。

安装包、客户端与各隧道的运行目录、脱敏日志都位于 **当前配置的数据目录 `/tools/natapp/`**，每个进程也在其中对应的隧道运行目录启动。配置和 authToken 保存在当前工作空间数据库，Token 通过既有本地凭据体系加密，页面不回显。启动所需的临时配置受本机权限保护，停止、退出或下次启动清理；输出日志有大小上限，不保留 Token。关闭窗口到托盘时隧道继续运行，真正退出栖点时停止；重新打开不会自动启动隧道。“运行中”表示客户端进程正在运行，实际穿透地址与连接结果以客户端日志为准。

客户端日志上报在线映射后，隧道列表自动显示 **访问地址**（`forwarding`）和 **本地映射**（`local`）。HTTP／HTTPS 访问地址可点击，通过系统默认浏览器打开；其他协议地址以文本显示。地址后的复制图标可复制完整地址；地址随当前运行更新，断开、停止或重新启动时清除旧值。启动按钮的图标为绿色，停止按钮的图标为红色，浅色和深色主题均适配。

迁移数据目录前需停止全部隧道并等待安装完成，安装包、客户端和日志随目录一起迁移。工作空间备份包含数据库中的加密配置，不包含客户端安装包、日志或运行时明文配置；恢复后按需重新安装客户端。本机加密主密钥仍使用栖点既有独立存储策略，不随工作空间备份导出。

## BUG 修复

左侧 **BUG 修复** 菜单（`/#/bugs`）独立管理禅道 BUG，不计入任务或执行。先在“设置 → 禅道连接”保存连接，再在 BUG 页面点击同步。依据 Token 当前账号读取可访问产品的 BUG，并严格筛选 `assignedTo` 为本人；不使用项目负责人或执行负责人代替 BUG 指派人，也不限制在“我参与”的项目内。

页面默认筛选“待解决”，并按禅道创建时间倒序排列，最新创建的 BUG 在前。状态、优先级、严重程度、创建时间、截止日期表头均可点击切换升序／倒序，箭头标识当前方向；排序先于分页，空日期始终排最后。状态升序为待解决 → 已解决 → 已关闭，优先级和严重程度按数值排序。页面支持项目、状态、严重程度、是否确认和关键词组合筛选；选择项目后，状态数量随项目范围更新。项目选项包含已同步的禅道项目，以及 BUG 缓存中尚未同步到项目页的项目；无归属的 BUG 可选择“未关联项目”。项目关联按连接 ID 与禅道远端项目 ID 匹配，不按名称或本地项目 ID 匹配。项目页与筛选数量均为当前个人 BUG 缓存，按禅道设置的频率自动更新，也可点击“同步我的 BUG”立即更新。页面可查看 BUG 描述、产品／项目、优先级与指派人，编辑及状态操作回写禅道。权限以禅道当前账号为准；远端确认成功后更新缓存。失败保留错误与编辑内容；写入超时不自动重放，应先同步核对。页面提供原站入口，附件、版本等高级配置仍可在禅道完成。

列表将优先级与严重程度分列展示，严重程度使用与禅道一致的火焰轮廓和内部等级数字：1 级暗红、2 级橙红、3 级金橙、4 级褐金；深色模式提亮 1 级红色以便辨认。悬停可查看等级说明，点击“严重程度”表头仍可排序。

列表与详情展示独立的“是否确认”：绿色“已确认”、橙色“未确认”，兼容浅色和深色主题；旧缓存或远端未提供确认字段时显示灰色“待同步”，不会误标为未确认。筛选栏的“是否确认”可选择全部确认状态、已确认或未确认，切换后回到第一页；“待同步”记录仅在全部确认状态下显示。“是否确认”表头支持排序，升序先显示未确认，未知值始终排最后。详情中的“确认”调用禅道官方确认功能，填写可选备注后提交；仅待解决且未确认的 BUG 可确认，已确认按钮禁用，未知状态须先同步核对。

未关闭 BUG 的详情提供独立“指派”入口，选人并填写可选备注后调用禅道指派功能。编辑 BUG、指派、解决或激活 BUG 时，“指派给”使用可搜索的禅道人员下拉，显示姓名和账号，支持按姓名或账号搜索，同名人员按账号区分，保存时提交账号。候选人员从当前 BUG 所属连接分页完整读取；加载失败可重试，当前指派保持不变。转派给其他人后，该 BUG 将移出“我的 BUG”。

打开 BUG 操作表单后，后台或手动同步若未发现内容变化，不会使表单版本失效，可继续提交已填写的指派和备注。若 BUG 内容或远端版本确实变化，仍会阻止旧表单提交；请先保留输入，再同步并重新打开详情核对后操作。

BUG 只读详情底部展示“历史记录”，同时显示指派人、指派时间与独立的创建人。指派来源取禅道历史中与当前指派对象匹配的最新指派记录；没有可核实记录时显示“未找到指派记录”，不把创建人当作指派人。历史按时间正序展示操作人、动作和备注，字段原值／新值可展开查看。打开详情时按需读取，失败可“重新加载历史”；关闭弹窗后的迟到结果不会覆盖其他 BUG。备注保留安全文字排版，图片备注提示在禅道查看，不直接加载外部图片或链接。该功能只读，不修改禅道，也不将历史全文写入本地缓存。

复现步骤支持文字排版和截图展示；点击截图打开接近整个窗口的看图画布，再点击图片即可放大／还原，支持滚轮缩放、拖动查看细节、缩放比例显示，以及原始尺寸／适应窗口切换。详情、编辑和大图预览中的截图均提供中文右键菜单，可复制或下载图片；点击预览右上角关闭按钮后保留 BUG 详情。图片通过当前 BUG 的远端引用与身份核验后读取，加载失败提供提示和重试，不直接访问 HTML 中的地址。编辑 BUG 时使用富文本编辑器，正常显示段落、列表、表格和已有图片；只打开、预览或未修改复现步骤时保持原始 HTML，预览数据不回写禅道。新增 BUG 图片和其他附件仍在禅道原站上传，当前不提供离线附件缓存。

点击“确认”“指派”“解决”“关闭”“激活”先打开操作表单，填写操作备注并提交后才回写禅道；切换表单不会自动提交空备注。提交失败保留输入。解决时可选择已修复、重复、设计如此、无法重现等方案；已修复需填写解决版本，重复需填写 BUG 编号。重新激活默认沿用禅道原影响版本，也可填写新版本。本人刚关闭的 BUG 可在下次同步清理前重新激活；会核对原指派账号、确认状态和远端版本，不允许直接操作已转派给别人的记录。

总览显示待解决、已解决、已关闭及严重待解决（严重程度 1／2 级）的数量，可直接进入对应状态列表。统计页新增 **BUG 修复** Tab，展示状态环图、严重程度柱图、创建／解决趋势及产品分布，支持图表数据表和深浅主题。

BUG 统计基于当前本地缓存，不是全公司的历史报表。下一次完整同步会移除转派给其他账号或不再返回的 BUG；解决、关闭操作若由禅道自动转派，后续同步也会移出。趋势使用远端 `openedDate`／`resolvedDate`，不把本地导入日期当作创建日期，缺失或无效日期不补造。BUG 同步与“项目与执行同步”分别触发，刷新统计只重读缓存，不调用远端同步。

BUG 缓存通过 migration 004 新增独立表，随工作空间备份和迁移；升级保留原任务、项目、邮箱和连接。模型 API Key 与账号配置的密文随数据库备份；本机主密钥以及独立加密凭据库中的禅道 Token、邮箱和日历密码不进入备份。

## 统计页面

左侧 **统计** 菜单，路由 `/#/statistics`。采用 Apache ECharts 6（Apache-2.0），按需引入图表和 Canvas 渲染器；仅进入统计页时加载图表模块。数据来自已有工作空间快照，MCP 配置通过只读 IPC 获取；无需额外统计数据库或外部分析服务。

| 视图 | 统计维度 | 图表 |
| --- | --- | --- |
| 工作与项目 | 新建/完成趋势、任务状态、项目任务进度、优先级、来源；完成率、逾期、未排期及项目明细 | 折线图、环形饼图、堆叠柱状图 |
| BUG 修复 | 当前 BUG 总数、待解决、已解决、已关闭、严重待解决；远端创建/解决日期趋势、严重程度、产品分布 | 环形饼图、柱状图、折线图 |
| 知识与应用 | 文档处理状态、知识库文档数量、文件格式、应用分类；原件逻辑大小、分块、收藏和技能关联 | 环形饼图、水平柱状图 |
| AI 与连接 | 聊天趋势、Agent 会话分布、每日发送消息、模型能力、供应商模型数量、助手回复状态；禅道/MCP 配置数量 | 折线图、日历热力图、柱状图、环形饼图及连接表 |

支持近 7 / 30 / 90 天趋势、刷新、图例筛选、悬停数值、数据表切换、长列表图表滚动、键盘切换统计 Tab。兼容浅色、深色、跟随系统及 900px 桌面窗口；空数据不生成演示图形或虚构比例。

统计口径：

- 顶部指标和分布图都是**当前存量**；“趋势范围”仅影响任务/BUG/聊天折线和消息热力图，不是历史快照筛选。
- 日期按当前设备本地自然日计算，包含今天，处理夏令时。缺失创建/完成时间的旧记录不补造时间。
- 任务完成率 = 当前已完成数 ÷ 任务总数，分母为零显示“暂无”。逾期按结束日期／时间统计未完成状态的过期任务，挂起计入未完成；未排期统计当前全部没有个人排期的任务。
- 完成趋势使用当前仍为已完成状态的任务及其 `completedAt`，不代表不可变事件流水；任务重开、删除或重新完成会改变结果。禅道导入时间是本地记录创建时间，不等于远端原始创建时间；同步工作项仅包含禅道执行。
- 文件大小按文档记录累加，是原件逻辑大小，不等于去重后磁盘占用或整个数据库大小。未知状态和缺失关联单独归组；同名分类、供应商与 Agent 按 ID 分开统计。
- 聊天统计只包含本地保留记录；关联知识库不等于每条消息都完成了检索。回复状态单独统计助手消息，停止、失败、中断有不同分组。
- 供应商、模型、MCP 等展示**配置数量与启用状态**，不表示实时连通、请求成功率或调用量。尚未采集 Token 用量、模型费用、应用打开次数和 MCP 调用次数，不显示推算数值。

统计验证使用 `npm test -- src/lib/statistics.test.ts`。`tests/statistics-browser.js` 在 Vite 页面中用 `agent-browser eval --stdin` 执行，通过隔离 iframe 的测试数据核对图表与交互；不写真实工作空间。统计截图中的测试数据不能当成用户实际数据。

## 预览边界

- 使用 12 条示例任务、12 个示例应用。日期固定为 2026-09-07，任务状态与各视图来自同一数据集。
- 支持导航、任务创建、开始/结束时间、筛选、拖拽与撤销、详情编辑、日历改期、月周日列表切换、应用增改与收藏。
- 应用分类支持新增、改名和删除；分类下拉框右侧提供管理链接。改名同步应用与筛选，删除引用中的分类需选择其他分类或未分类，操作后保留应用表单草稿与 Logo 文件。
- 项目页包含 3 个本地项目与 4 个禅道示例项目，支持本地项目增改、空项目删除、来源筛选、项目详情与任务计数。任务通过稳定项目 ID 关联；禅道来源项的所属项目只读，个人任务可自由选择项目。
- 从禅道同步项目的入口已提供，当前只引导配置连接。实际项目拉取、关系解析和远端同步尚未接入。
- 编辑只保留在本次页面会话中，重新加载将重置，不应当作正式工作记录使用。
- 禅道开源版 22.0 的服务地址和权限尚未配置。预览不会调用任何禅道 API，提交连接表单只提示预览限制并清空令牌输入，不保存凭据。
- 默认个人状态独立管理，可选显示禅道管理入口。实际能力必须在正式接入时核验；不将通用文档等同于 22.0 的完整兼容性证明。
- 窗口标题栏为视觉示意，未集成原生窗口 API。本轮没有 Tauri 二进制、安装包、数据库、通知、自动更新或真实同步。
- 设置中的大模型管理支持预设/自定义供应商、API 地址和协议、模型目录；API 密钥不保存，测试和获取模型不会发起网络请求。
- Agent 支持名称、描述、图标、提示词、供应商/模型、Temperature、最大输出 Token、复制与启停；嵌入模型不可用于对话。
- 聊天支持新会话、选择 Agent、历史会话、重命名、移除、消息复制、发送与停止。所有回复明确标记演示；切换 Agent 会创建独立会话，修改现有 Agent 不覆盖已有会话的配置快照。
- 技能支持新建、编辑、启停、删除及 Markdown / SKILL.md / JSON 文件导入（最大 256 KB），导入先预览确认，不执行其中的指令或脚本。Agent 可以关联多个技能，新会话保留技能内容快照。
- 知识库支持多个库、仅选择已启用的向量模型，以及 PPT/PPTX、DOC/DOCX、XLS/XLSX、TXT、MD、PDF 多文件添加和拖拽（单个最大 30 MB）。文件可移除或下载原件，只在会话中保留 File 对象，不写入持久存储。
- 聊天可选择一个知识库或不使用知识库，选择与消息上下文关联；文档保持待解析，演示回复不会伪造检索结果。文档提取、分块、向量化、检索和真实技能执行尚未接入。
- 被知识库引用的向量模型不能直接删除或更改模型 ID/能力；被历史消息引用的知识库不能直接删除。修改向量模型后文档需重新索引。

后续工程建议：Tauri 2 + React + TypeScript + SQLite。具体功能和数据规则见设计文档。

邮箱侧栏的“已发送”使用中间邮件列表与右侧正文布局；本机发送记录也直接在页面浏览，支持搜索、收件人、时间、投递状态和附件名称展示。若服务器已有已发送文件夹，本机记录单独标为“本机已发送”，避免混淆或重复合并；发送结果未确认的记录不会自动重发。

## 读取本机技能

在「设置 → 技能」点击「读取本机技能」，扫描当前用户的 `~/.codex/skills`、`~/.agents/skills`、`~/.claude/skills` 中的 `SKILL.md`，解析名称、描述和正文并保存到当前栖点工作空间。卡片显示来源路径，提供启用／停用滑块。新读取的技能默认停用，启用后可在「设置 → Agent」关联使用；停用或删除会阻止已有会话后续消息继续加载该技能，已经生成的历史回复不受影响。

扫描只读本机原文件，不改变其他工具的技能启停，不执行脚本。以规范文件路径去重，重复读取保留栖点内已有的内容与启停状态，不自动覆盖本地编辑。支持目录链接和嵌套目录；最多读取 500 项技能、5,000 个目录条目、6 层目录，单个 SKILL.md 不超过 256 KiB，格式或权限异常会提示跳过。当前仅导入指令正文，不复制引用文件、脚本或依赖，也不扫描插件缓存和任意项目目录；需这些资源的技能不代表可以在栖点完整执行。浏览器预览仅用于界面展示，实际读取与持久化需桌面 App。

技能页按实际来源分组：栖点技能（创建／文件导入）、公共 Agent、Codex、Claude、其他本机技能。顶部统计总数、已启用、已停用，支持技能名称／描述搜索与来源筛选；分组可展开查看详情，单项与整组均可启停，部分启用会显示数量。整组开关作用于该来源全部技能（不只搜索命中的条目），后端核验每项修订号并在单事务内更新，出现冲突时不部分提交。重新读取本机技能可为旧记录补充来源分类，同时保留原有编辑和启停。目录链接按原始扫描来源归类，规范路径相同的技能仍仅保留一份。

仅「栖点技能」允许修改名称、描述和指令内容。公共 Agent、Codex、Claude 等外部来源技能卡片提供「查看内容」，详情字段只读、可选择复制，不提供保存或删除；单项与整组启停保留。后端按已保存的来源信息校验，禁止通过普通保存接口改写外部技能内容或清除来源绕过限制。

## 任务到期提醒

在**新建任务／任务详情 → 到期提醒**中启用系统通知，选择**到期时、提前 15 分钟、提前 1 小时或提前 1 天**。提醒默认关闭，本地任务和禅道执行均可单独设置；开启前须填写有效的结束时间。提醒偏好只存于本地 SQLite，不回写禅道，同步会保留设置；若禅道撤销结束日期，则自动停用该任务的提醒。

原生后台每 30 秒检查一次，提醒基于排期结束时间和任务时区；全天任务沿用排期的半开区间，在界面结束日期的次日零点到期。仅提醒待做／正在做的任务，已完成、已挂起、无结束时间或未开启提醒的任务不提醒。关闭窗口后保留在托盘仍可提醒，完全退出后停止；重新打开或电脑唤醒后，仅补发触发时间距今不超过 24 小时的提醒。

同一任务、结束时间及提前量的通知提交记录持久保存，重启、普通编辑或再次同步不会重复提醒；修改结束时间或提前量可形成新的提醒。通知结果不明或提交失败时不自动重发。通知由系统决定是否展示，请在 macOS／Windows 通知设置中允许栖点通知，并检查勿扰模式。当前桌面通知插件无法可靠读取系统的实际展示权限，保存成功及通知提交成功均不代表弹窗已展示；浏览器预览不发送系统通知。

提醒设置及提交记录随工作空间备份恢复，数据库升级到 schema 8；旧版应用无法打开升级后的数据库。

## 任务备注富文本与禅道图片

任务详情的备注改为富文本编辑器，支持加粗、斜体、下划线、列表、撤销／重做及表格回显，不再展示 HTML 源码；看板摘要提取纯文字。支持插入、粘贴或拖入 PNG/JPEG/GIF/WebP 图片，单张不超过 5 MB，点击图片打开与 BUG 共用的桌面看图画布，支持点击放大／还原、滚轮缩放、拖动查看和适应窗口／原始尺寸切换，正文和预览中的图片均可通过中文右键菜单复制或下载，点击预览右上角关闭按钮返回；返回编辑器后仍可删除选中的图片。外部 HTML 先清理危险标签与属性，不执行脚本。

已同步的禅道执行可将 `{708.png}`、当前站点的 file-read 地址等图片引用解析为附件 ID，经原生后端使用已保存 Token 读取真实图片；读取前核对执行负责人、项目关联和远端描述中的图片引用，不向任意 HTML 地址发送凭据。图片暂时无法读取时显示明确提示及重试入口，原引用保留。编辑器只显示预览数据，保存仍使用原始图片引用，经 `save_task` 回写执行描述。

仅打开详情、预览图片、修改状态或保存失败重试时，未编辑的备注保持原样，不因编辑器初始化或禁用切换而重新序列化。禅道列表与详情接口对同一附件的占位符／本站图片地址转换按等价引用核验；正文、图片替换及其他属性的实际变化仍触发冲突保护，提示具体冲突字段，不自动覆盖远端修改。

上传由用户插入图片触发，使用禅道 22.0 的 `POST /api.php/v1/files`（multipart 字段 `imgFile`），成功后插入新图片引用；保存任务后同步正文。删除图片仅移除描述中的引用，不删除服务器附件。上传成功后取消编辑，已上传文件仍保留在禅道；未知上传结果不会自动重试。新建禅道执行须先保存，再上传图片。本地任务图片以数据形式随备注保存；禅道图片回显需要连接可用，当前不提供离线附件缓存。

验证使用模拟文件 API、临时数据与独立浏览器页面，覆盖图片占位回显、上传、删除、原引用保留、安全 HTML 和任务保存；未向用户真实禅道上传测试文件。接口兼容资料见 `docs/compatibility/zentao-22.0.md`。

任务新建／详情表单以红色星号标明必填项：任务名称、状态、优先级、时区；禅道关联项目及必需的开始／结束日期按实际规则显示。本地任务允许不关联项目、不排期，填写结束时间时开始时间为必填。

## 本地加密凭据

禅道、邮箱、钉钉日历和 MCP 的密码、令牌与认证配置统一使用本地加密凭据库；模型 API Key 和登录账号配置在 SQLite 中也以密文保存。macOS 与 Windows 使用同一 AES-256-GCM 认证加密实现，每次写入使用随机 nonce，并绑定工作空间与用途，不能把某个连接的密文挪给另一连接使用。密码、令牌和 API Key 不返回前端、不进入日志或源码，账号配置仅按表单需要解密回显。

每个工作空间使用系统随机数生成独立的 256 位主密钥，不使用固定口令或机器公开信息派生。主密钥与加密凭据文件分别放在本机应用数据目录 `com.self.workbench/credentials/keys` 和 `vaults` 下；macOS 基础目录为 `~/Library/Application Support`，Windows 为当前用户的本地应用数据目录。`vaults` 中另存不含密钥的 `.key-id` 指纹标记，防止运行期间密钥丢失后静默新建错误密钥。Unix 上目录权限为 `0700`、文件为 `0600`，写入使用跨进程锁与原子替换。重启无需再次输入已保存凭据，也不会弹出钥匙串授权。

升级会把旧数据库里的明文模型密钥、登录账号及相关配置历史转为密文，保留原数据关联和版本。旧钥匙串条目不会读取或删除，需在对应设置中重新输入一次密码或令牌；旧的“已保存凭据”标志会清除，避免界面误报已保存。

备份包含模型密钥和账号配置的密文，不包含本机主密钥以及独立凭据库中的密码/令牌。同机恢复、同机更换数据目录可继续解密；跨机恢复必须先保留并安全迁移原本机主密钥，登录密码仍需重新配置。主密钥丢失、密文损坏或验证失败时会明确报错，不会当作空数据覆盖。已有旧版明文备份不会被自动改写，应另行妥善保管。

此方案保护落盘凭据和备份中的内容，不使用用户主密码。能够同时读取本机主密钥与密文的当前用户进程仍可解密，这是取消系统钥匙串后的实际保护边界。

## 钉钉“我的日历”（CalDAV）

普通钉钉账号可使用客户端提供的 CalDAV 专用账号接入，无需在栖点配置开放平台应用。获取入口：钉钉日历 → 日历设置 → 同步 → 同步到其他日历 → 获取 CalDAV 账号。服务器、专用用户名和密码仅显示一次，请自行妥善保存；栖点不使用钉钉登录密码。

1. 打开栖点 **设置 → 钉钉日历**，填写服务器、CalDAV 用户名和专用密码。裸主机名自动补 HTTPS。
2. 直接点击 **保存并获取日历**，读取当前账号可用的日历列表，无需先关闭同步开关；启用开关会真实保存，重新打开仍保持勾选；未选择日历时设置页显示“已启用，待选择日历”，后台待选择完成后开始同步。
3. 选择钉钉 **“我的日历”**，勾选 **启用钉钉日历同步**，点击 **保存并同步**。
4. 日历左侧新增绿色 **钉钉日历**，支持独立显示／隐藏；点击日程查看起止时间、全天标记、地点及说明。日程只读，不作为任务统计，不支持拖拽回写，请在钉钉中修改。

同步由原生后台执行，默认每 5 分钟更新，设置中可调整或关闭；关闭窗口保留到菜单栏时也会继续运行，完全退出后停止。日历侧栏只保留“钉钉日历”显示开关，不展示同步按钮、状态、更新时间、范围或错误信息；这些信息与操作统一放在“设置 → 钉钉日历”。钉钉日历设置增加独立的 **手动同步** 按钮，始终可点击发起（仅请求执行期间暂时禁用），有未保存修改时先保存当前设置；未选日历时先获取列表，缺少账号或密码时显示具体提示，不再长期置灰。每轮查询过去 90 天至未来 365 天，范围显示在钉钉日历设置页；成功后替换当前日历缓存，失败保留旧日程并等待下一周期，不自动重新获取专用密码。服务器或账号更换时要求重新输入密码、重新发现并选择日历。

账号配置和只读缓存整体加密保存在 SQLite settings 记录中，可随工作空间备份；专用密码存入独立本地加密凭据库，按工作空间、站点与账号隔离，不进入备份。跨机恢复需原本机主密钥，并重新填写专用密码。后台刷新不会覆盖正在编辑的连接表单。

兼容边界：采用标准 CalDAV PROPFIND／REPORT；支持全天、UTC、IANA 时区及服务器展开的重复实例。**目前依赖服务器的 calendar-data expand 支持**，如果返回未展开的重复规则、浮动时间或未知时区，将明确报错并保留原缓存，不静默漏掉会议。单响应最多 16 MiB、日历最多 100 个、缓存最多 10000 个日程；超限、部分失败或不支持的分页不会覆盖缓存。裸主机地址先通过标准 `/.well-known/caldav` 发现入口；仅发现端点返回 404/405 时回退根地址。支持最多 5 次同源 301/302/307/308 跳转，保留 PROPFIND／REPORT 方法和正文，拒绝跨站、降级及循环跳转，不向其他站点发送凭据。错误提示包含实际 HTTP 状态码。

2026-09-11 无凭据核验：钉钉根路径 PROPFIND 返回 405；`/.well-known/caldav` 返回 302 指向同站 `/dav/principals/`，该入口无凭据时返回 Basic 认证 401。旧版直接查询根路径导致笼统“多状态响应”错误，已按标准发现流程修复；未使用真实账号验证日程同步。

已用隔离界面、模拟 CalDAV HTTP 和临时数据库验证；尚未使用用户真实钉钉账号联调，真实服务器的发现路径及重复日程展开能力需首次连接确认。

日历的日／周／月／列表视图保留已完成的个人任务、禅道执行，统一显示为灰色，并在标题上添加删除线；未排期列表同样处理。该展示按任务已完成状态判断，不以时间已过代替完成；钉钉 CalDAV 日程保持来源样式。

日历来源勾选框与右侧圆点保持同色：个人任务蓝色、禅道执行金色、钉钉日历绿色，浅色与深色模式分别保持一致。

钉钉日历目前只同步 CalDAV 日程。钉钉客户端内置待办不在此同步范围内，也不会显示在栖点日历中；保存钉钉设置时会停用旧版待办目录配置，避免继续发起无效读取。
