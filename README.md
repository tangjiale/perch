# 栖点 / Perch

栖点是一款本地优先的个人工作台。你可以在一个桌面应用里安排任务、跟进禅道项目和 BUG、处理邮件、记录会议，也能集中打开常用应用和工具。

[产品官网](https://tangjiale.github.io/perch/) · [下载安装](https://github.com/tangjiale/perch/releases/latest) · [开发指南](docs/CONTRIBUTING.md)

## 下载安装

- **macOS Apple Silicon**：下载 `.dmg`，打开后将栖点拖入「应用程序」。
- **Windows x64**：下载并运行 Release 提供的 Windows 安装包。

官网和 GitHub Release 提供已发布的安装包。下面介绍的是当前源码的功能，下载版包含哪些功能，以对应的 Release 更新说明为准。

现有构建流程未配置 macOS Developer ID 签名、公证或 Windows 平台代码签名。若 macOS 拦截从官方 Release 下载的安装包，确认来源可信并将栖点拖入「应用程序」后，可运行以下命令。

```sh
xattr -dr com.apple.quarantine "/Applications/栖点.app"
open "/Applications/栖点.app"
```

## 从哪里开始

| 想做什么 | 应用入口 |
| --- | --- |
| 看今天的安排和待办 | **总览**查看任务状态、今日安排、BUG 和常用应用。 |
| 管理项目和个人任务 | **项目 / 我的任务**支持本地项目、任务排期与提醒，以及看板、日历、列表和完成回顾。 |
| 同步禅道和钉钉日历 | **设置 → 禅道连接**配置项目、执行和 BUG 同步。**设置 → 钉钉日历**通过 CalDAV 只读同步日程，结果可在任务日历查看。 |
| 跟进 BUG | **BUG 修复**可新建本地或禅道 BUG，查看指派、处理进度和我解决的记录。复现步骤支持富文本和粘贴截图。 |
| 整理常用网站 | **应用中心**支持分类、收藏、从浏览器书签选取导入，以及用 Excel 批量导入。 |
| 管理团队常用链接 | **共享链接**支持新增和分组管理，可按名称、分组、创建人和创建日期筛选。 |
| 保存应用或服务器账号 | **密码库**按应用和服务器分开管理，支持 Excel 模板导入。密码默认隐藏，可按需查看或复制。 |
| 录音并整理会议 | **会议助手**支持实时转录、重点标记、定位回听、纪要和行动项。 |
| 收发多个邮箱的邮件 | **邮件**可搜索和阅读邮件、用富文本写信、保存草稿和发送附件。到**设置 → 邮箱设置**接入 IMAP 和 SMTP。 |
| 使用日常工具 | **工具箱**包含 NATAPP 内网穿透、2FA 验证码、汇率换算和提示词工具。 |
| 使用 AI 和本地知识库 | **聊天**支持模型选择、Agent 和带引用的知识库问答。到**设置**配置模型供应商、Agent、知识库和技能。 |

禅道完整同步成功后才更新本地缓存。项目和执行的实际字段有变化时才保存新版本，无变化时照常更新最近同步时间。

打开**工具箱 → NATAPP**，连接账号后可下载或在线更新客户端，并同步、配置或创建隧道。客户端安装后会检查官网版本。手头已有官方安装包时，可直接从文件安装或覆盖更新。更新前请先停止运行中的隧道。

## 会议录音与实时转录

1. 打开**设置 → 会议语音**，选择麦克风，点击「检测麦克风」，说话时可查看音量变化。
2. 下载 **X-ASR 160 ms（中英双语，INT8）**，约 128 MiB，下载完成后可离线转录。也可在此配置 API 转录。
3. 需要区分发言人时，选择 **X-ASR + 说话人识别**，下载 Pyannote + CAM++。录音中，文字按发言人直接出现在转录列表里。同一个人的连续发言会合并，换人后另起一段。同一次录音中再次发言仍用原来的编号。无法确认的发言可在录音结束后手动补标。
4. 在**会议助手 → 新建**开始录音。本机转录会跳过近乎静音时的识别结果。结束录音后可校对、回听，或使用已配置的 AI 模型生成纪要并把行动项转成任务。

160 ms 是模型处理的音频块长度，实际出字速度取决于设备和语音内容。模型存放在 `~/.perch/models/meeting-speech/`，可在会议语音设置里查看路径、单独卸载或重新下载。

## 数据存放与备份

- 默认工作空间是 `~/.perch`，工作数据保存在本机 SQLite。设备偏好和本机凭据使用操作系统的用户配置或数据目录。
- 模型 API Key 和登录凭据加密保存。外部集成需要在设置中配置对应账号或服务。
- 在**设置 → 数据与备份**可后台导出完整 ZIP、从文件还原，或配置 S3 兼容存储的手动和定时备份。还原校验成功后切换到新目录，原工作空间保留。
- S3 备份记录支持下载 ZIP 或直接还原。定时备份按系统时区运行，例如 `0 2 * * *` 表示每天凌晨 2 点。
- **S3 保留当前工作空间最新 10 份成功备份**，已有月度归档计入份数。上传成功并读取完整记录后，应用清理超出的旧备份。其他工作空间及其他对象不参与清理。
- 备份包含数据库和工作空间内的文档原件。模型文件、本机主密钥和独立登录凭据都在备份范围之外。跨机还原时，解密原工作空间中的密文需要原本机主密钥。

## 从源码运行

需要 Node.js 22+ 和 Rust。macOS 需要 Xcode Command Line Tools，Windows 需要 MSVC 构建工具和 WebView2。在仓库根目录运行：

```sh
npm ci
npm run runtime:prepare
npm run tauri dev
```

`runtime:prepare` 准备文档解析所用的随包运行时，支持 Apple Silicon macOS 和 Windows x64。`npm run dev` 可在浏览器预览界面，涉及原生功能和数据写入时使用桌面端。

```sh
npm test
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

在 Apple Silicon Mac 上构建本机安装包可运行 `npm run tauri build -- --bundles app,dmg`。
