# 栖点 / Perch

## 产品介绍

栖点（Perch）是一款面向个人工作的桌面工作台，把每天要做的事、项目推进、禅道执行与 BUG、日历、邮件和常用工具放在同一处管理。它帮助你快速确认今天该做什么、事项卡在哪里，以及下一步应该打开哪个工作入口。

### 名称含义

“Perch” 的英文含义是“栖息处、停留的位置”，也可以指鸟停留的枝头，发音接近“珀奇”。在栖点中，“栖点”代表个人任务、项目、日历、知识库和 AI 助手汇聚的工作落脚点；“Perch”是应用的英文品牌名，不是某个具体功能名称。中文界面以“栖点”为主。

- **任务与项目**：管理本地任务、项目和排期，以列表、看板和日历查看进度；可连接禅道，同步并在已确认后回写本人参与的执行与 BUG。
- **工作信息汇集**：集中查看钉钉 CalDAV 日历、多个邮箱、常用应用和工作统计，避免在多个页面之间反复切换。
- **AI 与知识辅助**：按需配置模型、Agent、技能和知识库，用于聊天、整理和辅助日常工作；模型请求只会在用户发送消息时发起。
- **本地优先与安全**：工作数据保存在本机 SQLite 数据库；API 密钥、禅道令牌和邮箱密码仅存入系统钥匙串，备份不包含这些凭据。

已开始按确认的架构开发，当前提供 **Tauri 2 + React + Rust + SQLite 的 macOS Apple Silicon 0.1.0 开发版本**。它使用真实本地数据库、原生文件选择、系统钥匙串和网络适配器。完整验收状态及架构差异见 [实现与验证记录](docs/IMPLEMENTATION.md)，不能将开发版本等同于全部架构工作包已完成。

## 运行与构建

要求 Node.js 22+、Rust；macOS 需要 Command Line Tools，Windows 需要 MSVC 构建工具与 WebView2。解析运行时支持 Apple Silicon macOS 和 Windows x64，随应用打包，无需全局 Java 或 PostgreSQL。

```bash
npm ci
npm run runtime:prepare
npm run tauri dev
npm test
cargo test --manifest-path src-tauri/Cargo.toml --lib
npm run tauri build -- --bundles app,dmg
```

macOS 安装包在 `src-tauri/target/release/bundle/dmg/`，App 在 `src-tauri/target/release/bundle/macos/`。目前没有 Developer ID 签名或公证。版本号已接入检查、下载和安装更新；正式更新源由 Tag 工作流注入，普通本地构建未配置更新源。

### macOS 首次打开未签名版本

当前 macOS 安装包尚未配置 Apple Developer ID 签名和公证。首次从浏览器下载后，系统可能提示“栖点.app 已损坏，无法打开”。请确认安装包来源可信，然后将应用拖入“应用程序”目录，在终端执行：

```bash
xattr -cr "/Applications/栖点.app"
open "/Applications/栖点.app"
```

也可以在 Finder 中右键点击应用，选择“打开”，并在系统提示中确认。正式发布版本配置 Developer ID 签名和公证后，不需要执行上述操作。

推送 `vX.Y.Z` Tag 后自动构建 macOS Apple Silicon 和 Windows x64，并在双平台成功后统一发布 Release。中文提交约定、多个 commit 的更新说明汇总、首次签名配置见 [发布与在线更新](docs/RELEASE.md)。

默认数据位置为 `~/.perch`。在设置的“数据与备份”中更改路径、备份和恢复。API 密钥与禅道令牌存在系统钥匙串，不包含在备份中；换电脑后需要重新配置凭据。

`npm run dev` 提供 React 浏览器界面预览，端口默认 1420；业务数据写入只能在桌面 App 内完成。原 `ui/` 设计预览继续保留。

## 当前功能入口

禅道项目列表与项目详情显示“计划开始日期 / 计划结束日期”，分别同步项目自身的 `begin / end`，不使用执行排期推算。日期为空或无效时显示“未设置”；已有连接升级后同步一次即可补齐。禅道项目计划日期只读，本地项目原有截止日期保持。

项目页采用紧凑五列布局：项目／负责人、计划日期、任务进度、BUG 进度、操作。状态标记紧邻名称，长描述最多两行，无描述不占行；禅道 HTML 描述转为安全纯文本，保留原描述供详情查看和编辑。任务进度按当前关联任务展示待做、正在做、已完成、已关闭的数量与分布，不代表远端项目整体进度。点击项目名称或任务进度查看关联任务；BUG 进度展示总数、待解决、已解决、已关闭及状态分布，点击进入该项目的 BUG 列表。本地项目显示“未关联禅道”。右侧保留添加任务和编辑项目入口；支持深浅主题及窄窗口。

已关闭任务在看板和列表中使用灰色标题及删除线显示，弱化来源和辅助信息；仍可打开详情和拖动恢复状态，已关闭后不再显示过期标签，也不计入逾期数量；重新打开后按结束时间判断。

任务看板卡片底部分两行显示开始和结束日期；定时任务显示具体时间，全天任务显示包含当天的实际结束日，缺失日期标为“未设置”。任务看板支持拖动卡片右上角手柄，在同一状态列排序，或移动到待做、正在做、已完成、已关闭任意列的顶部、中间和末尾；拖入两张卡片之间时显示插入空位，下方卡片自动让位。松手后以明确插入位置原子保存本地顺序，支持同排序值任务，重新打开及禅道同步后保留已有顺序。保存中暂时禁用拖动，失败保持原位置；可撤销最近一次成功拖动。同列排序不请求禅道，跨状态的禅道执行仍需远端身份、权限和状态变更核验，失败不会假装成功。

禅道任务卡片右上角与项目名称旁新增“在禅道中打开”图标，在默认浏览器进入对应执行／任务或项目详情；本地任务与项目不显示。链接保留禅道安装子目录且不携带令牌，浏览器未登录时需先登录禅道。

“在禅道管理”、应用卡片及更新日志通过系统默认浏览器打开 HTTP/HTTPS 网页，支持内网 IP、端口和子路径。Tauri 同时需要打开命令权限与 URL 范围；本项目已配置网页范围，不开放本地文件 URL 或任意指定程序。若旧安装包提示 `Not allowed to open url`，安装修复版并完全退出旧进程后重新打开，权限配置不会热更新。

打开禅道网页和连接认证是独立动作：网页跳转不自动向栖点授权 API；连接认证直接在禅道设置页的“账号登录”或“访问令牌”中完成。
禅道设置采用单连接页面，直接展示连接名称、地址、API 版本和认证表单，不再通过连接列表打开配置弹窗。顶部保留“同步项目与执行”和“在禅道管理”；未保存连接时按钮禁用。已有连接配置直接载入，保存仍更新原连接及关联数据。

**令牌失效自动登录**：在“设置 → 禅道连接 → 账号登录”中勾选“记住登录凭据，令牌失效后自动重新登录”，输入账号密码并登录保存一次即可启用。日常拉取与修改仍复用令牌；读取请求明确返回 401 时才用系统钥匙串中保存的凭据自动获取新令牌，最多尝试一次。自动登录失败后暂停，需重新配置；403 权限不足和网络超时不触发登录。写入请求不自动重放，结果不明先同步核对。密码仅存系统钥匙串，不进数据库和备份；取消勾选保存或换成手动令牌会清除记住的凭据。

**账号配置回显**：保存后记住所选登录方式和账号，重新打开时恢复。账号与密码输入框对齐；已记住的密码只用固定星号掩码显示，原密码不会返回界面。点击“修改密码”才进入新密码输入，点击“保留原密码”取消修改。未修改密码时保存配置会复用已有令牌及凭据，不重新登录。HTTP 选项根据同一连接在系统钥匙串中保存的许可状态恢复，不跨地址或账号复用。关闭“记住登录凭据”会清除已保存的密码，但保留账号和登录方式方便下次填写；未记住或换设备后不显示虚假的已保存密码。

**个人同步范围**：每次同步先通过 `/api.php/v1/user` 识别 Token 所属账号，再使用 v1 `projects?involved=1` 查询禅道“我参与”的项目（创建者、项目负责人、团队成员、干系人或白名单成员）。全局执行目录请求 `fields=PM`，只导入这些项目中 `PM.account` 与当前账号一致的执行（包含已关闭），不把“有权限查看”当作“与我相关”。没有负责人或负责人不是本人则排除；账号识别或负责人字段核验失败时中止，不回退到全量同步。即使连接选择 v2，这条个人同步链路仍使用具备明确筛选语义的 v1。不会自动重新同步，需点击同步按钮。

**只同步执行**：不请求执行下的具体任务，也不读取独立任务目录。下次成功同步会通过当前连接的工作项差集清理此前导入的禅道任务；自建任务和其他连接不受影响。

**新建任务关联禅道项目**：在“新建任务”选择禅道项目，保存时会在该项目创建一个禅道执行，成功后自动保存执行编号、负责人和项目关联；后续编辑、拖动状态、日期调整复用执行回写流程。选择自建项目或不关联项目时仅创建本地任务。已有本地任务改关联项目不会追溯创建执行。

默认按禅道“添加执行”简洁版：短期迭代、初始未开始（工作台显示待做）、当前 Token 账号为执行负责人及团队成员；任务名称对应执行名称，备注对应执行描述，计划开始／结束日期必填，结束日包含当天。选择禅道项目会自动切换全天日期，保留已填日期；没有开始日期时默认今天。关联产品、计划和可用工作日不自动填充，执行代号使用稳定草稿标识自动生成，兼容开启代号的实例。22.0 v1 根据项目模型派生执行方式，因此仅支持可创建迭代的 Scrum／融合敏捷项目；其他模型、已关闭或未开启多执行的项目会提示在禅道中创建后再同步。

创建前核验项目、当前账号、排期与本地版本。POST 不自动续登重放；提交记录持久保存在工作空间，阻止同一草稿重复提交。超时或结果不明时，先同步并在禅道核对是否已创建，不要立即重新新建。远端成功但本地保存／页面刷新失败会明确提示；不会显示为普通本地任务创建成功。

**禅道同步**：进入“设置 → 禅道连接 → 同步项目与执行”。按服务端分页信息读完相关项目与全局执行目录，再核验负责人、状态和项目关联。读取失败时不发布、不清理旧数据；成功后原子保存项目及执行，清理不再符合范围的旧工作项。状态和排期按禅道更新，备注保留。本地模拟验证不等于真实账号验收。

## 邮件与多邮箱设置

在 **设置 → 邮箱设置 → 添加邮箱** 中填写显示名称、邮箱地址、发件人名称及 IMAP / SMTP 参数。预设仅填写服务器地址，可继续修改；用户名留空时使用邮箱地址，发件人名称留空时使用显示名称。先在邮箱服务商处开启 IMAP / SMTP；QQ / Foxmail、网易及开启双重验证的邮箱通常需要邮箱授权码或应用专用密码。收发凭据独立保存在系统钥匙串；新邮箱的发信凭据留空时使用收信凭据，编辑现有邮箱时留空保留原值。仅支持 SSL/TLS 与必须升级加密的 STARTTLS，不降级为明文。

左侧 **邮件** 菜单提供：

- 多账号折叠与切换；收件箱、已发送、服务器草稿、已删除、垃圾邮件、归档和其他服务端文件夹；另提供本地草稿与发送记录。
- 1440px 三栏阅读；窄窗口自动切换为列表 / 阅读区，通过返回按钮回到列表。支持当前文件夹缓存搜索、未读和星标筛选。
- 阅读时标为已读、切换已读 / 未读及星标、移动至其他文件夹或已删除。移动依赖服务器支持 IMAP MOVE，不支持时明确提示，不执行可能影响其他邮件的全局清除。
- 写邮件、回复、回复全部、转发正文；收件人 / 抄送 / 密送使用逗号分隔；附件添加、移除及下载。转发正文不自动附带原附件，如需转发附件可先保存再选择。
- 本地草稿需点击“保存草稿”；点击“发送”才通过 SMTP 投递。发送副本尝试保存到服务器的已发送文件夹。SMTP 接受、发送中和结果未确认的记录可在“发送记录”中查看；不确定结果不会自动重发，需先核对网页邮箱或与收件人确认。SMTP 接受不代表收件人已阅读。
- HTML 正文经过清理并放入无脚本沙箱；默认纯文本，可切换排版正文。外部图片、跟踪资源、活动内容与正文内导航被禁用，附件由用户选择保存路径。

**未读刷新**：每个账号默认每 1 分钟检查，可选 3 / 5 / 15 分钟。原生后台调度与页面独立，隐藏到托盘仍继续；退出程序、设备休眠或网络断开时不能收信。菜单角标汇总已启用邮箱的收件箱未读数，超过 99 显示 `99+`；以服务端 UNSEEN 统计为准，不受缓存条数限制。后台事件刷新页面，同时每 15 秒重读本地未读统计；实际新邮件发现时间受检查间隔及服务器耗时影响，并非 IMAP IDLE 推送。

**缓存与兼容范围**：当前同步每个打开文件夹的最近 200 封邮件，自动检查同步收件箱；首次加载后复用已缓存正文。邮件列表支持主题、发件人与摘要搜索，搜索中的 `%`、`_` 和反斜杠按普通字符匹配；已修复查询转义导致已缓存邮件报“邮件数据库操作失败”的问题，无需清空缓存。单封上限 25 MB、每次最多 100 MB、最多 200 个文件夹，超限会提示。发送附件最多 20 个、合计 18 MB。密码 / 授权码认证已实现，OAuth、POP3、Exchange、邮件规则与远程草稿双向同步尚未实现；仅允许 OAuth 的邮箱需另行适配。

邮箱元数据、收信原文及附件缓存进入现有 SQLite，通过新增 migration 002 升级，随工作空间备份与迁移；当前备份为 schema 4，兼容恢复 schema 1/2/3 旧备份。凭据不进入数据库或备份，换设备后需重新填写。草稿附件引用选择时的原文件，发信前须保持原路径可读取。移除账号只清除本地邮箱配置和缓存，不删除服务器邮件。

## 关闭行为与系统托盘

桌面 App 内禁用 WebView 默认右键菜单（包括邮件正文嵌入区域），保留文字选择、复制粘贴快捷键及系统托盘菜单。页面与内部滚动区域关闭边界回弹和滚动穿透，列表、聊天及邮件仍可正常滚动；浏览器预览保留浏览器右键菜单。

顶部全局搜索聚焦时，焦点描边沿包含搜索图标的完整圆角外框显示，兼容浅色、深色和键盘聚焦。

顶部栏显示系统本地时间的公历年月日、星期、时分秒和农历月日，每秒更新；恢复窗口时立即校准，跨日自动更新日期。日期、星期、时分秒和农历同一行分隔展示；农历使用独立的 lunar-typescript 计算，避免不同 WebView 的 Intl 中文日数差异导致缺失，不依赖联网；时钟独立刷新，避免每秒重绘整个工作台，兼容深浅主题和窄窗口。

**设置 → 通用设置 → 关闭主窗口时**：

- 默认“最小化到菜单栏 / 托盘”：关闭按钮隐藏主窗口并保留后台运行。macOS 在顶部菜单栏、Windows 在通知区域显示与桌面应用一致的彩色栖点 Logo；托盘直接复用应用图标资源，不再单独绘制旧图案。
- 可改为“关闭窗口并退出应用”。也可随时在托盘右键菜单选择“退出栖点”。
- 悬停显示今日待办、正在做、逾期数量及最多三条任务摘要；每 30 秒刷新，鼠标进入时也更新。点击恢复主窗口，右键可打开任务待办或退出。macOS Dock 重新打开和单实例激活也能恢复隐藏窗口。
- 设备关闭偏好使用 Tauri 应用配置目录中的 `device-settings.json` 原子保存，不随工作空间切换。若托盘创建失败，会提示并允许正常退出，避免留下无法找回的隐藏窗口。

验证：邮件后端测试覆盖 MIME、IMAP UID / FLAGS / STATUS、密送、发送互斥及 SQLite 备份恢复；托盘测试覆盖偏好保存、任务摘要与日期边界。`tests/mail-browser.js` 通过隔离模拟 IPC 检查多邮箱、阅读、回复、草稿、发送与通用设置；未使用用户凭据、未发送真实邮件。真实邮箱 TLS / 认证、Mac 托盘交互与 Windows 桌面行为仍需安装后的原生验收。

## 拉取供应商模型

进入 **设置 → 大模型管理 → 添加供应商 / 配置 → 保存并拉取模型**。先保存当前名称、API 根地址、协议和密钥，再打开模型选择弹窗。API Key 留空保留已有密钥；本地免密服务可留空。密钥仅保存在系统钥匙串。

- 支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages。目录请求为 API 根地址追加 `/models`；例如 `http://localhost:8000/v1` 对应 `/v1/models`。Anthropic 目录支持自动分页。
- 弹窗支持名称 / ID 搜索、全选当前筛选结果、清空选择与选中计数。已添加的模型显示标记且不能重复勾选。确认后一次性保存，按供应商与远端模型 ID 去重，不覆盖已有模型的配置。
- 目录通常没有能力信息，勾选后默认“文本”；请按实际能力选择“视觉”或“向量”。文本用于文字聊天，视觉用于图片与文字聊天，向量用于知识库。不根据名称推算向量维度；用于知识库前仍需确认供应商支持相应接口。
- 模型导入和模型编辑的类型采用直接可见的“文本 / 视觉 / 向量”三段式单选，点击即可切换，无需展开下拉浮层。先勾选待添加模型，再选择类型；支持键盘操作和浅深色模式。
- 模型列表的状态列提供启用 / 禁用滑块，点击直接保存；每行提供删除按钮，确认后移除本地模型配置。被 Agent 或知识库引用的模型需先解除引用才能删除；操作期间防止重复提交，保存失败会提示并保留原状态。
- 拉取失败可重试，空目录不能提交；保存成功但刷新失败时仅重试刷新。供应商配置变化或工作空间切换 / 恢复后，需要重新拉取目录。浅色与深色模式均使用现有玻璃弹窗和 GlassSelect。
- 不支持标准模型目录的服务仍可通过供应商卡片“添加模型”手动配置。非标准 OpenAI 分页会明确报错，不将首批结果当作完整目录。最多 5000 个模型、20 页，每页 2 MiB，单请求 20 秒、总拉取 60 秒；不跟随重定向。

验证：`cargo test --manifest-path src-tauri/Cargo.toml --lib provider_models` 覆盖本地 HTTP、认证、分页、错误和临时 SQLite 批量导入；`tests/provider-models-browser.js` 用隔离 iframe 模拟 IPC 验证界面流程。模拟验证不代表真实供应商已联调。

## 禅道负责人和执行范围

农历、节气、节假日及休／班标记在日历中始终显示，不增加左侧日历类型或开关；左侧仍只筛选个人任务和禅道执行。月历日期旁显示农历日数（初一显示月份）、传统节日或节气；日／周日期标题同步显示，小日历提供休／班角标。绿色「休」代表官方放假安排，橙色「班」代表调休上班，悬停可查看节日名称和说明；普通周末不冒充法定假日。显示层只提供日期信息，不生成任务、不修改排期或参与任务统计。

放假调休采用 lunar-typescript 内置中国大陆年度安排，当前完整覆盖 2002–2026；未收录年份提示仅显示农历与节气，不推算未来调休。2026 年数据已与[国务院办公厅通知（国办发明电〔2025〕7号）](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)逐日核对：9 月 20 日上班、9 月 25–27 日中秋放假、10 月 1–7 日国庆放假、10 月 10 日上班。内置数据离线可用，后续年度需随数据更新提供；当前不包含企业自定义假期或个人请假记录。

**定时自动同步**：在「设置 → 禅道连接 → 自动同步频率」配置并保存，默认每 5 分钟，可选 1 / 5 / 10 / 15 / 30 / 60 分钟或关闭。原生后台启动约 5 秒后执行首轮，随后从每轮完成时开始计时，自动拉取我参与的项目、我负责的执行（包含已关闭）及指派给我的 BUG。同步完成后自动刷新看板、BUG、总览和统计；最小化到托盘仍运行，退出应用或设备休眠时不执行。新连接和未配置过频率的已有连接默认启用每 5 分钟同步。

自动与手动同步共用连接锁，避免重叠请求；复用已保存令牌和既有 401 续登规则，不每轮账号登录。两类数据分别成功后更新缓存，失败保留该类缓存并等待下一周期，不连续弹窗；设置页可查看项目执行及 BUG 最近成功同步时间。后台刷新不会清空正在编辑的连接表单。定时器和设置已用模拟数据验证，真实禅道连通性仍取决于当前网络、账号权限和令牌状态。

**统一任务日期**：任务表单只保留开始、结束日期／时间与时区，移除独立截止日期。日历、过期标签、统计和托盘统一使用排期；没有结束日期时不自动判定过期。旧工作空间及旧备份会在升级时迁移：已有结束日期的排期保持不变，旧的独立截止日期不再参与计算；仅有截止日期的记录转换为该日期的全天排期。项目自己的截止日期不属于任务排期，本次保持。

**已过期标签**：看板、列表、详情和日历事件使用红色文字及淡红背景显示“已过期”，兼容浅色、深色模式，已关闭任务不显示；待做、正在做、已完成任务仍按结束时间判断。仅使用排期结束日期／时间；全天排期的结束日已包含在范围中，到下一天才过期。没有有效结束日期不标记。页面每分钟及重新获得焦点时刷新标签；过期标记不会修改任务状态。

**看板状态与日历排期**：禅道“未开始 / 进行中 / 已完成 / 已关闭”与本地“待做 / 正在做 / 已完成 / 已关闭”对应。鼠标拖动按实际指针落点识别卡片及状态列，支持从长任务列拖入空的“已完成”“已关闭”列；使用卡片右上角拖动手柄操作。拖动看板变更状态、编辑任务名称及备注、修改日期或拖动日历排期时，会通过官方执行编辑接口更新禅道；本地自建任务仍仅保存在本地。执行使用 begin / end，仅支持全天日期，修改排期需同时填写开始和结束日期，结束日包含当天。例如 9 月 8 日到 10 日，会在 8、9、10 日均显示。已关闭执行在后续同步时继续保留，并计入总览、项目任务分布及统计页的已关闭数量。

**禅道回写结果**：远端更新成功后才保存本地并显示成功。权限不足、连接失败或数据冲突时显示错误；写入结果不明时不自动重试，应先重新同步核对。执行所属项目保持与禅道一致，个人优先级和看板排序仍为本地设置。拖动失败时看板保留错误提示；HTTP 401 表示令牌失效或认证被拒绝，可点击“重新登录禅道”，编辑原连接重新登录或更新令牌，同步后再拖动。HTTP 403 应检查当前账号执行查看与编辑权限。

禅道同步补充：项目负责人从远端 PM 保存到项目的负责人字段；执行卡片显示执行负责人。执行要求 `PM.account` 为当前 Token 账号；包含已关闭执行，映射到工作台“已关闭”，但仍不读取执行下的具体任务。下次成功同步会在同一事务移除当前连接中已不符合范围的旧工作项，保留自建任务、其他连接数据以及仍在范围内任务的备注（状态按禅道同步映射更新）。网络、权限或关联核验失败时整轮不发布，不会提前删除旧数据。

## 预置 Agent

首次打开包含此功能的版本，会为当前工作空间补齐五个助手：任务助手（拆解、优先级、阻塞与交付）、通用聊天（问答、写作和总结）、财务助手（预算、核对与报表）、法务助手（合同、条款与风险）、IT 助手（开发、排障和运维）。在“设置 → Agent”查看、修改或删除，聊天页可选择已启用的助手。

预置优先关联已启用供应商下的文本模型，其次选择视觉模型；没有可用模型时保持停用，需要在 Agent 配置中选择模型并启用。每个工作空间只初始化一次，不覆盖已有同 ID 助手，不恢复用户主动删除的预置，也不覆盖后续编辑。任务助手当前产出行动计划和交付内容，不会自动修改工作台或禅道任务；财务、法务和 IT 提示词要求明确依据和适用范围，不编造数据、条文或执行结果。

聊天消息采用“右侧用户气泡＋左侧助手正文”布局：自己的消息靠右，Agent 回复直接排版，不带气泡背景、边框或阴影，历史消息与流式回复保持一致；自己的气泡省去重复称呼，短消息保持一行；复制按钮位于气泡外，悬停或键盘聚焦显示。气泡随内容收缩，长文本换行，代码与表格在各自消息区域内滚动，兼容深浅主题。AI 回复正文底部集中显示复制、Token 用量、模型请求耗时和完成时间，移除回复右上角复制按钮；用量来自供应商实际返回；达到 1,000 tok 后以 K 为单位并保留两位小数（例如 7,460 → 7.46K tok），不足 1,000 显示整数，悬停仍可看输入／输出的精确明细。缺失用量显示“未提供”，历史消息缺失耗时显示“未记录”，不按文本长度估算。用量与耗时随消息保存，兼容 OpenAI Chat Completions、Responses 和 Anthropic Messages 协议。聊天输入区底部依次展示添加图片、当前模型和知识库选择，发送按钮位于右侧；窄窗口下工具栏自动换行，避免与输入框重叠。没有历史会话时输入框保持可编辑，首次发送绑定所选 Agent 与知识库。新建会话前检查 Agent、聊天模型及供应商是否可用；配置有误显示中文指引并保留输入。首次发送失败后复用已创建会话重试，避免重复生成空会话。

## 视觉模型与图片聊天

在 **设置 → 大模型管理** 中将支持图片的模型类型设为“视觉”，然后在 **设置 → Agent** 中为助手选择该模型。进入聊天，选择该 Agent 即可输入或添加图片，首次发送时自动创建会话，也可手动点击“新会话”；已有会话所用模型的类型修改也会立即生效。Agent 或远端模型名称改动后，应新建会话使用新配置，已有会话保留创建时的配置快照。

- 点击“添加图片”选择文件，或在消息框中粘贴图片。发送前显示缩略图、文件名，可逐张移除；支持纯图片或图文一起发送，发送失败保留草稿。
- 支持 PNG、JPEG、WebP、GIF，每条最多 4 张，单张最多 5 MiB、合计最多 12 MiB。后端核验真实文件签名和 Base64 数据；文本模型禁止发送图片，向量模型不能聊天。
- 支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 三种协议的图片请求格式；服务端模型本身必须支持视觉，修改类型不会为纯文本模型增加视觉能力。
- 图片保存在本地消息数据中，重启后仍能查看，随工作空间备份与恢复一起保留。对话上下文最多取最近 20 条消息，当前与历史图片合计最多 12 MiB，超限截断较早历史。
- 图片和文字会在点击发送时传给该会话配置的模型供应商。选择知识库但仅发送图片时不执行文字检索；附上文字问题后才会同时检索知识库。

验证：图片读取限制单元测试、模型类型与图片聊天浏览器模拟 IPC 测试、Rust 图片格式 / 三协议编码 / SQLite 重开历史图片测试。未使用真实供应商密钥进行视觉推理验收。

禅道 22.0 创建执行时同时在 URL 查询参数与 JSON 正文传入相同的远端项目编号，避免接口覆盖正文项目值后误报“所属项目不能为空”。新建任务的禅道执行说明默认收起，点击“所属项目”标签右侧的感叹号可展开或收起中性样式说明。创建禅道执行时会读取远端项目的计划日期，并在提交前检查任务日期是否超出项目范围。HTTP 400／422 会显示禅道返回的可安全展示的字段校验信息（例如名称、开始日期或结束日期），不会再把创建接口的这类错误提示为连接失效；非结构化响应不直接展示。创建失败保留表单内容，未知结果仍禁止自动重复 POST，需先在禅道核对。

## BUG 修复

左侧 **BUG 修复** 菜单（`/#/bugs`）独立管理禅道 BUG，不计入任务或执行。先在“设置 → 禅道连接”保存连接，再在 BUG 页面点击同步。依据 Token 当前账号读取可访问产品的 BUG，并严格筛选 `assignedTo` 为本人；不使用项目负责人或执行负责人代替 BUG 指派人，也不限制在“我参与”的项目内。

页面默认筛选“待解决”，并按禅道创建时间倒序排列，最新创建的 BUG 在前。状态、优先级、严重程度、创建时间、截止日期表头均可点击切换升序／倒序，箭头标识当前方向；排序先于分页，空日期始终排最后。状态升序为待解决 → 已解决 → 已关闭，优先级和严重程度按数值排序。页面支持项目、状态、严重程度和关键词组合筛选；选择项目后，状态数量随项目范围更新。项目选项包含已同步的禅道项目，以及 BUG 缓存中尚未同步到项目页的项目；无归属的 BUG 可选择“未关联项目”。项目关联按连接 ID 与禅道远端项目 ID 匹配，不按名称或本地项目 ID 匹配。项目页与筛选数量均为当前个人 BUG 缓存，按禅道设置的频率自动更新，也可点击“同步我的 BUG”立即更新。页面可查看 BUG 描述、产品／项目、优先级与指派人，编辑及状态操作回写禅道。权限以禅道当前账号为准；远端确认成功后更新缓存。失败保留错误与编辑内容；写入超时不自动重放，应先同步核对。页面提供原站入口，附件、版本等高级配置仍可在禅道完成。

解决时可选择已修复、重复、设计如此、无法重现等方案；已修复需填写解决版本，重复需填写 BUG 编号。重新激活默认沿用禅道原影响版本，也可填写新版本。本人刚关闭的 BUG 可在下次同步清理前重新激活；会核对原指派账号和远端版本，不允许直接操作已转派给别人的记录。

总览显示待解决、已解决、已关闭及严重待解决（严重程度 1／2 级）的数量，可直接进入对应状态列表。统计页新增 **BUG 修复** Tab，展示状态环图、严重程度柱图、创建／解决趋势及产品分布，支持图表数据表和深浅主题。

BUG 统计基于当前本地缓存，不是全公司的历史报表。下一次完整同步会移除转派给其他账号或不再返回的 BUG；解决、关闭操作若由禅道自动转派，后续同步也会移出。趋势使用远端 `openedDate`／`resolvedDate`，不把本地导入日期当作创建日期，缺失或无效日期不补造。BUG 同步与“项目与执行同步”分别触发，刷新统计只重读缓存，不调用远端同步。

BUG 缓存通过 migration 004 新增独立表，随工作空间备份和迁移；升级保留原任务、项目、邮箱和连接。凭据仍仅存系统钥匙串，备份不携带 Token 或密码。

## 统计页面

左侧 **统计** 菜单，路由 `/#/statistics`。采用 Apache ECharts 6（Apache-2.0），按需引入图表和 Canvas 渲染器；仅进入统计页时加载图表模块。数据来自已有工作空间快照，MCP 配置通过只读 IPC 获取；无需额外统计数据库或外部分析服务。

| 视图 | 统计维度 | 图表 |
| --- | --- | --- |
| 工作与项目 | 新建/完成趋势、任务状态、项目任务进度、优先级、来源；完成率、逾期、未排期及项目明细 | 折线图、环形饼图、堆叠柱状图 |
| BUG 修复 | 当前 BUG 总数、待解决、已解决、已关闭、严重待解决；远端创建/解决日期趋势、严重程度、产品分布 | 环形饼图、柱状图、折线图 |
| 知识与应用 | 文档处理状态、知识库文档数量、文件格式、应用分类；原件逻辑大小、分块、收藏和技能关联 | 环形饼图、水平柱状图 |
| AI 与连接 | 聊天趋势、Agent 会话分布、每日发送消息、模型能力、供应商模型数量、助手回复状态；禅道/MCP 配置数量 | 折线图、日历热力图、柱状图、环形饼图及连接表 |

支持近 7 / 30 / 90 天趋势、刷新、图例筛选、悬停数值、数据表切换、长列表图表滚动、键盘切换统计 Tab。兼容浅色、深色、跟随系统及 900px 桌面窗口；空数据不生成演示图形或虚构比例。

统计口径：

- 顶部指标和分布图都是**当前存量**；“趋势范围”仅影响任务/BUG/聊天折线和消息热力图，不是历史快照筛选。
- 日期按当前设备本地自然日计算，包含今天，处理夏令时。缺失创建/完成时间的旧记录不补造时间。
- 任务完成率 = 当前已完成数 ÷（任务总数 − 已关闭数），分母为零显示“暂无”。逾期按结束日期／时间统计非关闭状态的过期任务；未排期统计当前全部没有个人排期的任务。
- 完成趋势使用当前仍为已完成状态的任务及其 `completedAt`，不代表不可变事件流水；任务重开、删除或重新完成会改变结果。禅道导入时间是本地记录创建时间，不等于远端原始创建时间；同步工作项仅包含禅道执行。
- 文件大小按文档记录累加，是原件逻辑大小，不等于去重后磁盘占用或整个数据库大小。未知状态和缺失关联单独归组；同名分类、供应商与 Agent 按 ID 分开统计。
- 聊天统计只包含本地保留记录；关联知识库不等于每条消息都完成了检索。回复状态单独统计助手消息，停止、失败、中断有不同分组。
- 供应商、模型、MCP 等展示**配置数量与启用状态**，不表示实时连通、请求成功率或调用量。尚未采集 Token 用量、模型费用、应用打开次数和 MCP 调用次数，不显示推算数值。

统计验证使用 `npm test -- src/lib/statistics.test.ts`。`tests/statistics-browser.js` 在 Vite 页面中用 `agent-browser eval --stdin` 执行，通过隔离 iframe 的测试数据核对图表与交互；不写真实工作空间。统计截图中的测试数据不能当成用户实际数据。

## 预览边界

- 使用 12 条示例任务、12 个示例应用。日期固定为 2026-09-07，任务状态与各视图来自同一数据集。
- 支持导航、任务创建、开始/结束时间、筛选、拖拽与撤销、详情编辑、日历改期、月周日列表切换、应用增改与收藏。
- 应用分类支持新增、改名和删除；分类下拉框右侧提供管理链接。改名同步应用与筛选，删除引用中的分类需选择其他分类或未分类，操作后保留应用表单草稿与 Logo 文件。
- 项目页包含 3 个本地项目与 4 个禅道示例项目，支持本地项目增改、空项目删除、来源筛选、项目详情与任务计数。任务通过稳定项目 ID 关联；禅道来源项的所属项目只读，个人任务可自由选择项目。
- 从禅道同步项目的入口已提供，当前只引导配置连接。实际项目拉取、关系解析和远端同步尚未接入。
- 编辑只保留在本次页面会话中，重新加载将重置，不应当作正式工作记录使用。
- 禅道开源版 22.0 的服务地址和权限尚未配置。预览不会调用任何禅道 API，提交连接表单只提示预览限制并清空令牌输入，不保存凭据。
- 默认个人状态独立管理，可选显示禅道管理入口。实际能力必须在正式接入时核验；不将通用文档等同于 22.0 的完整兼容性证明。
- 窗口标题栏为视觉示意，未集成原生窗口 API。本轮没有 Tauri 二进制、安装包、数据库、通知、自动更新或真实同步。
- 设置中的大模型管理支持预设/自定义供应商、API 地址和协议、模型目录；API 密钥不保存，测试和获取模型不会发起网络请求。
- Agent 支持名称、描述、图标、提示词、供应商/模型、Temperature、最大输出 Token、复制与启停；嵌入模型不可用于对话。
- 聊天支持新会话、选择 Agent、历史会话、重命名、移除、消息复制、发送与停止。所有回复明确标记演示；切换 Agent 会创建独立会话，修改现有 Agent 不覆盖已有会话的配置快照。
- 技能支持新建、编辑、启停、删除及 Markdown / SKILL.md / JSON 文件导入（最大 256 KB），导入先预览确认，不执行其中的指令或脚本。Agent 可以关联多个技能，新会话保留技能内容快照。
- 知识库支持多个库、仅选择已启用的向量模型，以及 PPT/PPTX、DOC/DOCX、XLS/XLSX、TXT、MD、PDF 多文件添加和拖拽（单个最大 30 MB）。文件可移除或下载原件，只在会话中保留 File 对象，不写入持久存储。

邮箱侧栏的“已发送”使用中间邮件列表与右侧正文布局；本机发送记录也直接在页面浏览，支持搜索、收件人、时间、投递状态和附件名称展示。若服务器已有已发送文件夹，本机记录单独标为“本机已发送”，避免混淆或重复合并；发送结果未确认的记录不会自动重发。

## 读取本机技能

在「设置 → 技能」点击「读取本机技能」，扫描当前用户的 `~/.codex/skills`、`~/.agents/skills`、`~/.claude/skills` 中的 `SKILL.md`，解析名称、描述和正文并保存到当前栖点工作空间。卡片显示来源路径，提供启用／停用滑块。新读取的技能默认停用，启用后可在「设置 → Agent」关联使用；停用或删除会阻止已有会话后续消息继续加载该技能，已经生成的历史回复不受影响。

扫描只读本机原文件，不改变其他工具的技能启停，不执行脚本。以规范文件路径去重，重复读取保留栖点内已有的内容与启停状态，不自动覆盖本地编辑。支持目录链接和嵌套目录；最多读取 500 项技能、5,000 个目录条目、6 层目录，单个 SKILL.md 不超过 256 KiB，格式或权限异常会提示跳过。当前仅导入指令正文，不复制引用文件、脚本或依赖，也不扫描插件缓存和任意项目目录；需这些资源的技能不代表可以在栖点完整执行。浏览器预览仅用于界面展示，实际读取与持久化需桌面 App。

技能页按实际来源分组：栖点技能（创建／文件导入）、公共 Agent、Codex、Claude、其他本机技能。顶部统计总数、已启用、已停用，支持技能名称／描述搜索与来源筛选；分组可展开查看详情，单项与整组均可启停，部分启用会显示数量。整组开关作用于该来源全部技能（不只搜索命中的条目），后端核验每项修订号并在单事务内更新，出现冲突时不部分提交。重新读取本机技能可为旧记录补充来源分类，同时保留原有编辑和启停。目录链接按原始扫描来源归类，规范路径相同的技能仍仅保留一份。

仅「栖点技能」允许修改名称、描述和指令内容。公共 Agent、Codex、Claude 等外部来源技能卡片提供「查看内容」，详情字段只读、可选择复制，不提供保存或删除；单项与整组启停保留。后端按已保存的来源信息校验，禁止通过普通保存接口改写外部技能内容或清除来源绕过限制。

## 任务备注富文本与禅道图片

任务详情的备注改为富文本编辑器，支持加粗、斜体、下划线、列表、撤销／重做及表格回显，不再展示 HTML 源码；看板摘要提取纯文字。支持插入、粘贴或拖入 PNG/JPEG/GIF/WebP 图片，单张不超过 5 MB，点击图片可打开大图预览，支持适应窗口／原始尺寸切换，按 Esc、关闭按钮或预览空白处关闭；返回编辑器后仍可删除选中的图片。外部 HTML 先清理危险标签与属性，不执行脚本。

已同步的禅道执行可将 `{708.png}`、当前站点的 file-read 地址等图片引用解析为附件 ID，经原生后端使用已保存 Token 读取真实图片；读取前核对执行负责人、项目关联和远端描述中的图片引用，不向任意 HTML 地址发送凭据。图片暂时无法读取时显示明确提示及重试入口，原引用保留。编辑器只显示预览数据，保存仍使用原始图片引用，经 `save_task` 回写执行描述。

仅打开详情、预览图片、修改状态或保存失败重试时，未编辑的备注保持原样，不因编辑器初始化或禁用切换而重新序列化。禅道列表与详情接口对同一附件的占位符／本站图片地址转换按等价引用核验；正文、图片替换及其他属性的实际变化仍触发冲突保护，提示具体冲突字段，不自动覆盖远端修改。

上传由用户插入图片触发，使用禅道 22.0 的 `POST /api.php/v1/files`（multipart 字段 `imgFile`），成功后插入新图片引用；保存任务后同步正文。删除图片仅移除描述中的引用，不删除服务器附件。上传成功后取消编辑，已上传文件仍保留在禅道；未知上传结果不会自动重试。新建禅道执行须先保存，再上传图片。本地任务图片以数据形式随备注保存；禅道图片回显需要连接可用，当前不提供离线附件缓存。

验证使用模拟文件 API、临时数据与独立浏览器页面，覆盖图片占位回显、上传、删除、原引用保留、安全 HTML 和任务保存；未向用户真实禅道上传测试文件。接口兼容资料见 `docs/compatibility/zentao-22.0.md`。

任务新建／详情表单以红色星号标明必填项：任务名称、状态、优先级、时区；禅道关联项目及必需的开始／结束日期按实际规则显示。本地任务允许不关联项目、不排期，填写结束时间时开始时间为必填。

## macOS 钥匙串授权

禅道、邮箱、模型和 MCP 凭据统一存储到当前工作空间的系统钥匙串凭据库，按业务来源隔离；应用运行期间复用内存缓存，正常重启只读取一次统一凭据库，不再按每个邮箱分别读取钥匙串。Windows 保持原独立凭据条目。

首次升级会在业务实际使用时迁移旧条目，因此第一次仍可能逐项出现系统授权。迁移成功后新版本不再读取对应旧项；为避免破坏性清理，旧项暂时保留，删除通过新库墓碑阻止重新导入，降级旧版本仍可能使用旧凭据。新库拒绝访问后本次运行不反复弹出读取授权，请完全退出应用后重新授权。缓存只存在当前进程，外部修改或锁定钥匙串不会撤回已经读入的凭据，重启后重新读取。

系统写入凭据、替换应用或临时签名身份变化仍可能要求授权，不能承诺永久免密码。当前安装包没有稳定 Developer ID 签名；系统弹窗中的“始终允许”可记住当前受信任应用，但后续重新构建后仍可能重新确认。不会修改钥匙串为允许所有应用访问，也不会将密码移到 SQLite、配置文件或备份中。

## 钉钉“我的日历”（CalDAV）

普通钉钉账号可使用客户端提供的 CalDAV 专用账号接入，无需在栖点配置开放平台应用。获取入口：钉钉日历 → 日历设置 → 同步 → 同步到其他日历 → 获取 CalDAV 账号。服务器、专用用户名和密码仅显示一次，请自行妥善保存；栖点不使用钉钉登录密码。

1. 打开栖点 **设置 → 钉钉日历**，填写服务器、CalDAV 用户名和专用密码。裸主机名自动补 HTTPS。
2. 直接点击 **保存并获取日历**，读取当前账号可用的日历列表，无需先关闭同步开关；启用开关会真实保存，重新打开仍保持勾选；未选择日历时设置页显示“已启用，待选择日历”，后台待选择完成后开始同步。
3. 选择钉钉 **“我的日历”**，勾选 **启用钉钉日历同步**，点击 **保存并同步**。
4. 日历左侧新增绿色 **钉钉日历**，支持独立显示／隐藏；点击日程查看起止时间、全天标记、地点及说明。日程只读，不作为任务统计，不支持拖拽回写，请在钉钉中修改。

同步由原生后台执行，默认每 5 分钟更新，设置中可调整或关闭；关闭窗口保留到菜单栏时也会继续运行，完全退出后停止。日历侧栏只保留“钉钉日历”显示开关，不展示同步按钮、状态、更新时间、范围或错误信息；这些信息与操作统一放在“设置 → 钉钉日历”。钉钉日历设置增加独立的 **手动同步** 按钮，始终可点击发起（仅请求执行期间暂时禁用），有未保存修改时先保存当前设置；未选日历时先获取列表，缺少账号或密码时显示具体提示，不再长期置灰。每轮查询过去 90 天至未来 365 天，范围显示在钉钉日历设置页；成功后替换当前日历缓存，失败保留旧日程并等待下一周期，不自动重新获取专用密码。服务器或账号更换时要求重新输入密码、重新发现并选择日历。

配置和只读缓存保存在现有 SQLite settings 记录中，可随工作空间备份迁移；专用密码仅存系统钥匙串，按工作空间、站点与账号隔离，不进入备份。换电脑或恢复到没有凭据的环境后需重新填写专用密码。后台刷新不会覆盖正在编辑的连接表单。

兼容边界：采用标准 CalDAV PROPFIND／REPORT；支持全天、UTC、IANA 时区及服务器展开的重复实例。**目前依赖服务器的 calendar-data expand 支持**，如果返回未展开的重复规则、浮动时间或未知时区，将明确报错并保留原缓存，不静默漏掉会议。单响应最多 16 MiB、日历最多 100 个、缓存最多 10000 个日程；超限、部分失败或不支持的分页不会覆盖缓存。裸主机地址先通过标准 `/.well-known/caldav` 发现入口；仅发现端点返回 404/405 时回退根地址。支持最多 5 次同源 301/302/307/308 跳转，保留 PROPFIND／REPORT 方法和正文，拒绝跨站、降级及循环跳转，不向其他站点发送凭据。错误提示包含实际 HTTP 状态码。

2026-09-11 无凭据核验：钉钉根路径 PROPFIND 返回 405；`/.well-known/caldav` 返回 302 指向同站 `/dav/principals/`，该入口无凭据时返回 Basic 认证 401。旧版直接查询根路径导致笼统“多状态响应”错误，已按标准发现流程修复；未使用真实账号验证日程同步。

已用隔离界面、模拟 CalDAV HTTP 和临时数据库验证；尚未使用用户真实钉钉账号联调，真实服务器的发现路径及重复日程展开能力需首次连接确认。

日历的日／周／月／列表视图保留已完成和已关闭的个人任务、禅道执行，统一显示为灰色，并在标题上添加删除线；未排期列表同样处理。该展示按任务已完成／已关闭状态判断，不以时间已过代替完成；钉钉 CalDAV 日程保持来源样式。

日历来源勾选框与右侧圆点保持同色：个人任务蓝色、禅道执行金色、钉钉日历绿色，浅色与深色模式分别保持一致。

钉钉日历目前只同步 CalDAV 日程。钉钉客户端内置待办不在此同步范围内，也不会显示在栖点日历中；保存钉钉设置时会停用旧版待办目录配置，避免继续发起无效读取。
